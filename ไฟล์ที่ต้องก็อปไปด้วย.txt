====================================================
  SET Dashboard — ไฟล์ที่ต้องก็อปไปด้วยเวลาย้ายเครื่อง
  (อัปเดตหลัง refactor เป็น core/ sources/ services/ static/)
====================================================

[ จำเป็นต้องมี — โค้ด ก็อปทุกไฟล์/โฟลเดอร์นี้ ]

  start.bat                    ← ดับเบิ้ลคลิกเปิดโปรแกรม
  app.py                       ← Flask Web Server (หัวใจหลัก)
  set_data_fetcher.py          ← โค้ดดาวน์โหลดข้อมูลจาก Yahoo Finance
  set_dashboard.html           ← โครง HTML ของหน้าเว็บ
  requirements.txt             ← รายการ Library ที่ต้องติดตั้ง
  listedCompanies_en_US.xlsx   ← รายชื่อหุ้น SET (ดาวน์โหลดจาก set.or.th)

  core/                        ← metrics.py (สูตรคำนวณ RS/EMA), store.py (persistence)
  sources/                     ← yahoo.py, tradingview.py, sec.py, dr_universe.py (HTTP clients)
  services/                    ← refresh.py (orchestration), breadth.py (market breadth)
  static/                      ← dashboard.css, dashboard.js (แยกออกจาก HTML)

----------------------------------------------------

[ ข้อมูลที่ดาวน์โหลดแล้ว — ก็อปด้วยถ้าไม่อยากรอ Full Refresh ใหม่ (~1-2 ชม.) ]

  set_prices.db         ← ราคาย้อนหลังทุกตัว (SQLite) — แหล่งหลักของ Breadth/Market Internals ~130 MB
  set_history.json      ← ประวัติราคาย้อนหลัง (ใช้กราฟ 5Y/Max + EMA200) ~95 MB
  set_data.json         ← ข้อมูลหุ้นทุกตัว (ราคา, RS, EMA, Fundamentals) ~13 MB
  dr_cache.json         ← ข้อมูล DR/DRx ต่างประเทศ ~30 MB
  indices_cache.json    ← ข้อมูลดัชนีกลุ่ม 30+ ดัชนี ~4 MB
  nvdr_data.json        ← ข้อมูล NVDR (ต่างชาติถือครอง)
  short_sales_data.json ← ข้อมูล Short Sales
  set_market_stats.json ← สถิติ PE/PBV ตลาดรวม
  rotation_state.json   ← state ของ Rotation alert (กลุ่มไหนแจ้งเตือนไปแล้ว)
  Table_PE.xls          ← ข้อมูล valuation อ้างอิงราย sector
  Table_PBV.xls         ← ข้อมูล valuation อ้างอิงราย sector

  ** ถ้าไม่ก็อปไฟล์ข้อมูล → ต้อง Full Refresh ใหม่ในเครื่องใหม่ (~1-2 ชั่วโมง)

----------------------------------------------------

  logs/                    ← log ของ waitress (สร้างใหม่เอง)

  response.txt             ← log ชั่วคราว
  server_out.txt           ← log ชั่วคราว
  server_err.txt           ← log ชั่วคราว
  test_batch.py            ← script test ภายใน
  test_syms.py             ← script test ภายใน
  ttm_test_results.json    ← ผลลัพธ์ test ภายใน

     import_eod_archive.py, import_market_stats.py, import_short_sales.py,

====================================================

[ ขั้นตอนหลังก็อปไปเครื่องใหม่ ]

  1. วางทั้งโฟลเดอร์ไว้ที่ไหนก็ได้ในเครื่องใหม่ (ต้องก็อป core/ sources/ services/ static/
     ไปพร้อมกันด้วย ไม่งั้น app.py จะ import ไม่เจอแล้วรันไม่ขึ้น)
  2. ตรวจสอบว่าติดตั้ง Python 3.10+ แล้ว
     → โหลดที่ python.org (ติ๊ก "Add to PATH" ตอนติดตั้ง)
  3. ดับเบิ้ลคลิก start.bat
     → จะติดตั้ง Library อัตโนมัติครั้งแรก (flask, yfinance, pandas, waitress ฯลฯ)
  4. Browser เปิดขึ้นเองที่ http://localhost:5001
  5. ถ้าไม่ได้ก็อปไฟล์ข้อมูล → กด Full Refresh เพื่อดาวน์โหลดใหม่
