4. Sensitivity ของ Regime threshold

ทดสอบหลายค่าเพื่อดู "ความทนทาน" ไม่ใช่หาค่าสวยสุด — ถือเงินสดเมื่อ %>EMA200 < X:

35+100%+6.9%−53.9%70/121
40+63%+4.8%−42.1%82/121
50+55%+4.3%−32.1%95/121
สิ่งที่ robust (เห็นตรงกันทุก threshold):
  • Regime filter ฆ่าหายนะตลาดหมียาว 2018–2019 ได้จริง (จาก −36.6%/−25.3% เป็น +1.9%/+2.4%)
  • MaxDD ลดลงเป็นขั้นบันไดตาม threshold (−62% → −32%) — เป็น trade-off ที่เลือกได้ ไม่ใช่ magic number
  • ทุก variant ชนะ Universe EW ขาด = การเลือกหุ้นด้วย RS มี edge จริงในตลาดไทย
สิ่งที่เปราะ (อย่าเชื่อ):
  • ตัวเลข +136% เกาะที่ X=30 พอดี — X=25 ให้แค่ +64% แปลว่า CAGR peak มีส่วนของโชคเชิง parameter
  • ปี 2024 regime version แพ้ของเดิมหนัก (−14% vs +19.6%) — ตลาด whipsaw ที่ breadth แกว่งรอบเส้น ทำให้เข้าออกผิดจังหวะ
  • Win rate ต่ำ (13–48%) — ชนะด้วยปีใหญ่ไม่กี่ปี (2021 คนเดียวแบกผลรวม) ต้องทนแพ้บ่อยได้

5. ที่มาของ Market Regime Light บน Dashboard

จากผลข้างบน dashboard แสดงไฟ 3 โซนจาก % หุ้นเหนือ EMA200 ของทั้งตลาด (คำนวณสดจาก /api/breadth) — ใช้ "โซน" แทนเส้นเดียวเพราะ sensitivity บอกว่าตัวเลขเป๊ะๆ ไม่ robust แต่ทิศทางของโซน robust:

🟢 Risk-On ≥ 50 ช่วงที่ signal RS สูงทำงานได้ดีตามประวัติศาสตร์

🟡 Caution 30–50 โซน whipsaw (แบบปี 2024) — ระวังการเข้าออกถี่ พิจารณาลดขนาด position

🔴 Risk-Off < 30 ทุก threshold ที่ทดสอบเห็นตรงกันว่าช่วงนี้ออกจากตลาดคุ้ม (คือช่วงแบบ 2018–2019)

ไฟนี้คือ "บริบทของตลาด" ไม่ใช่คำสัญญาผลตอบแทน และไม่ใช่คำแนะนำการลงทุน

6. ข้อจำกัดของผลลัพธ์ (สำคัญไม่แพ้ตัวเลข)

  1. Survivorship bias — ใหญ่ที่สุด: universe คือ 912 ตัวที่รอดถึงวันนี้ หุ้นที่ถูกเพิกถอนหายไปจากข้อมูล และกลยุทธ์แนว momentum มีโอกาสเคยถือหุ้นเหล่านั้น (หุ้นร้อนแรง RS 99 ก่อนพัง) → ผลจริงแย่กว่านี้
  2. Sector ปัจจุบันถูกใช้ย้อนหลัง: บริษัทที่เคยย้ายหมวดจะถูกจัดผิดในอดีต กระทบ RRG filter โดยตรง
  3. ไม่รวมเงินปันผล: ทั้งฝั่ง strategy และ SET Index (เทียบกันแฟร์ แต่ตัวเลข absolute ต่ำกว่าจริง ~3%/ปี)
  4. สภาพคล่องจำลองหยาบ: ไม่มี ceiling/floor, หุ้นติด SP ใช้ราคา ffill แทน (ขายไม่ได้จริง), slippage หุ้นเล็กต่ำกว่าจริง
  5. ไม่มี robustness ของ parameter อื่น: RS≥90 / top 10 / 21 วัน เลือกครั้งเดียว — ข้อดีคือไม่ overfit ข้อเสียคือไม่รู้ความไวต่อการขยับ
  6. ไม่มี stop loss / ถืองวดตายตัว 21 วัน — ไม่ตรงพฤติกรรมเทรดจริงของคนส่วนใหญ่
