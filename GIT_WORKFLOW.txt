[Laptop] - ทุกวัน ทุกครั้งแก้โค้ด

  2. Commit + Push ขึ้น GitHub (รันบน PowerShell หรือ Command Prompt)

     git push

  📝 ตัวอย่างการใช้จริง:

✅ เช็คลิสต์ก่อน Push
================================================================================

  ก่อน git push ทุกครั้ง:

  □ ตรวจสอบไฟล์ที่ staged (git add)
    git status

  □ ดูว่า commit message เข้าใจ
    git log --oneline -5

  □ ถ้าไม่รู้ commit ของใครเป็นอะไร อย่า push ก่อน


📋 คำสั่งใช้บ่อย
================================================================================

  git status              → ดูสถานะปัจจุบัน
  git add .              → เพิ่มไฟล์ทั้งหมด
  git commit -m "..."    → บันทึก (message ภาษาไทย/อังกฤษได้)
  git push               → ส่งขึ้น GitHub
  git pull               → ดึงโค้ดล่าสุด
  git log --oneline -5   → ดูประวัติ 5 commit ล่าสุด
  git diff               → ดูความแตกต่างก่อน commit


💡 Tips
================================================================================

  1. Commit บ่อยๆ = ถ้ามี bug สามารถย้อนกลับได้ดี

  2. Message ชัดเจน = 3 เดือนหลังมาอ่านเข้าใจได้ว่าทำอะไร

  3. Push ทุกวันก่อนปิดเครื่อง = ข้อมูลปลอดภัย GitHub

  4. Pull ทุกครั้งเปิดเครื่อง = โค้ดเป็นล่าสุด


🤖 Claude Code ช่วยเขียน Commit Message
================================================================================

  ถ้าแก้โค้ดหลายอย่างและงง commit message ต้องเขียนยังไง:

  1. เปิด Claude Code ที่ terminal/IDE ของโปรเจกต์

  2. รัน:
     git diff --stat
     git status

  3. Copy output มาให้ Claude โดยพิมพ์:
     "help commit message"

  4. Claude จะวิเคราะห์ code ที่เปลี่ยนแล้วเขียน commit message ให้

  ตัวอย่าง:
     git diff --stat
     [Output: sources/screener.py | 45 +++, app.py | 12 +++]

     → "help commit message"

     Claude ตอบ: feat: เพิ่ม screener filter + fix port 5001 (sources/screener.py, app.py)

     → Copy ไปพิมพ์:
     git commit -m "feat: เพิ่ม screener filter + fix port 5001"
