------------------------------------------------------------------------
 ที่มา / โจทย์
------------------------------------------------------------------------
เมนู "หุ้นโตแรงรายไตรมาส" โชว์ กำไรสุทธิ + QoQ/YoY แต่กำไรสุทธิรวม
"รายการครั้งเดียว" (FX, mark-to-market อนุพันธ์, ด้อยค่า) ทำให้ QoQ/YoY
หลอก — หุ้นดู "โตแรง" ทั้งที่ธุรกิจจริงไม่ได้โต (หรือกลับกัน)

ต้องการ: แยกกำไรสุทธิเป็น
  - กำไรปกติ  = กำไรจากธุรกิจหลัก (recurring)
  - กำไรพิเศษ = รายการไม่เกิดประจำ (non-recurring)

เทียบ 4 แหล่งแล้ว (2026-09-04):
  SET P&L รายไตรมาส  — มี account code 439700 "กำไร(ขาดทุน)อื่น" แยกชัด
                        มาตรฐาน SET ตรงกันทุกบริษัท  ← เลือกอันนี้
  Yahoo yahoo_q      — มี Normalized Income สำเร็จรูป แต่ช้า 1 ไตรมาส +
                        auto-detect เพี้ยนกับหุ้นไทยบางตัว
  SET company-highlight (set) — profitFromOtherActivity เป็นรายปี/6M เท่านั้น
  Finnomena finnomena_q — มี income แค่ 5 บรรทัด ไม่มีทางแยก

ผู้ใช้ยืนยัน: ปกติดูแค่ไตรมาสล่าสุด → ข้อจำกัดเรื่อง "ลึกแค่ ~4 ไตรมาส"
ของ SET ไม่กระทบ use case จริง

 สูตร / นิยาม
------------------------------------------------------------------------
account code (SET taxonomy — ยืนยันแล้วว่า parent = ผลรวม children):
  439700  กำไร(ขาดทุน)อื่น           ← parent total ใช้ตัวนี้ตรง ๆ
    439710  จากอัตราแลกเปลี่ยน (FX)
    439720  จากเครื่องมือการเงิน FVTPL (อนุพันธ์ mark-to-market)
    439770  จากการบัญชีป้องกันความเสี่ยง (hedge)
    439790  อื่น ๆ
  431000  (กลับรายการ)ขาดทุนลดมูลค่าสินค้าคงเหลือ  ← option: รวมด้วย
  431100  ส่วนแบ่งกำไร(ขาดทุน)บริษัทร่วม (equity method) ← ไม่รวม (recurring)

หน่วย: SET รายงานเป็น "พันบาท" → ×1000 (เหมือน field อื่นใน _set_qpl_amt_map)
หมายเหตุตำแหน่ง: 439700 อยู่ "เหนือ" บรรทัด EBIT 409992 ในงบ SET
  → operating_profit / net_profit ปัจจุบันรวม 439700 อยู่แล้ว
  → "กำไรปกติ" = ถอด 439700 ออก

  special_pretax     = amt(439700)              (+ amt(431000) ถ้าเปิด option)
  etr                = tax_expense / pretax_profit   guard → clamp [0, 0.35],
                       fallback 0.20 ถ้าหารไม่ได้
  special_after_tax  = special_pretax * (1 - etr)
  core_profit        = net_profit - special_after_tax
  special_share_pct  = |special_after_tax| / |net_profit| * 100
  core_profit_yoy    = pct_change(core_profit, core_profit ของ Q เดียวกันปีก่อน)
                       — None ถ้าปีก่อนไม่มี 439700 หรือฐาน <= 0

badge ⚡ "กำไรพิเศษ": โชว์เมื่อ special_share_pct >= 20 AND
                      |net_profit| >= 50 ลบ. (GROWTH_SCR_MIN_BASE กันฐานจิ๋ว)

edge:
  - net_profit = "ผู้ถือหุ้นบริษัทใหญ่" (ไม่รวม NCI) แต่ 439700 เป็นก่อนแบ่ง
    NCI → มี error เล็กน้อยในหุ้นที่ NCI เยอะ ยอมรับได้
  - ไม่มี 439700 ในงบ → special = None (กลุ่มการเงิน) หรือ 0 (นอกกลุ่ม
    การเงินที่ไม่แยกบรรทัด) — สองเคสนี้ต่างกัน ดูข้อ [1]/[3]
