================================================================================
 อัพเดทงบการเงินรายไตรมาส ให้เวอร์ชันมือถือ/iPad เห็นงวดใหม่
================================================================================

ทำเมื่อไหร่ : หลังบริษัทประกาศงบไตรมาสใหม่ — ก.พ. / พ.ค. / ส.ค. / พ.ย.
              (รอบปกติ ~กลางเดือน + รอบเก็บตกต้นเดือนถัดไปสำหรับหุ้นที่ยื่นช้า)

ไฟล์ที่เกี่ยว : data/financials_quarterly.json
              = งบกำไรขาดทุนรายไตรมาส (รายได้/กำไรขั้นต้น/กำไรจากดำเนินงาน/
                กำไรสุทธิ) จาก SET.or.th official — แสดงในแท็บ "งบการเงิน" ของ
                หน้าหุ้นบนเว็บมือถือ (section "กำไรขาดทุนรายไตรมาส")
              เก็บสะสมได้ ~16 ไตรมาสล่าสุด · งวดใหม่ merge เข้าของเดิม ไม่ทับ

สำคัญ : รอบ auto-update ของ GitHub (วันละ ~4 รอบ) "ไม่" แตะไฟล์นี้
        (เพราะ CI ไม่มี financials.db) — อัพเดทเฉพาะตอน push มือเท่านั้น
        ถ้าลืมทำ ก็ไม่พัง — มือถือแสดงงวดล่าสุดที่ push ไว้ ไม่มี error


--------------------------------------------------------------------------------
 ขั้นตอน (ทำในโน้ตบุ๊ค — เว็บมือถือทำเองไม่ได้)
--------------------------------------------------------------------------------

1. เปิดโปรแกรม
      double-click start.bat   (หรือ  python app.py)
   รอจนเบราว์เซอร์เปิดหน้า dashboard

2. Sync งบการเงิน  (ไฟล์ financials_quarterly.json จะถูกสร้างใหม่ให้เองตอนจบ)

   วิธี A — ปุ่มในแอป (แนะนำ ไม่ต้องพิมพ์คำสั่ง)
      เมนู  🩺 Data Health  →  กดปุ่ม  "🔄 อัพเดทงบการเงินทั้งหมด"
      รอ ~5–30 นาที (ขึ้นกับจำนวนหุ้นที่มีงวดใหม่)

   วิธี B — คำสั่ง (เทียบเท่าปุ่ม A)
      python update_financials.py
      (หรือ double-click update_financials.bat)

3. เช็คว่างวดใหม่เข้าแล้ว  (เลือกอย่างใดอย่างหนึ่ง)
   - Data Health → รายการ "🗓️ เช็คงวดล่าสุดงบการเงิน" ต้องขึ้นไตรมาสใหม่
   - เปิดไฟล์ data/financials_quarterly.json → ค้น "PTT" → ต้องมี key
     ไตรมาสล่าสุด เช่น  "2026Q3"

4. push ขึ้น GitHub
      git add data/financials_quarterly.json
      git commit -m "data: งบไตรมาส Q3/2569"
      git push

   พิมพ์คำสั่งได้ที่ : VS Code → Terminal (Ctrl+~)  /  PowerShell  /  Git Bash
   หรือใช้แถบ Source Control ของ VS Code (Ctrl+Shift+G) กด stage → commit → Sync

5. เช็คบน iPad  (รอ GitHub Pages build ~1–2 นาที)
      เปิด  https://crazyass669.github.io/SET-IPAD/mobile/
      → เลือกหุ้น → แท็บ "งบการเงิน" → เลื่อนดู section "กำไรขาดทุนรายไตรมาส"
      กราฟแท่งรายได้ + ตาราง 8 งวดล่าสุด ต้องมีไตรมาสใหม่


--------------------------------------------------------------------------------
 รอบเก็บตก (ต้นเดือนถัดไป — ถ้าต้องการ)
--------------------------------------------------------------------------------

หุ้นบางตัวยื่นงบช้า (กำหนด 45–60 วันหลังปิดงวด บางตัวลากไปต้นเดือนถัดไป)
→ รันข้อ 2 ซ้ำอีกครั้ง → หุ้นที่ยังไม่มีงวดใหม่จะถูกดึงเพิ่ม (ตัวที่มีแล้วข้าม)
→ push ใหม่ (ข้อ 4–5)


--------------------------------------------------------------------------------
 ถ้าอยากอัพเดทข้อมูลอื่นไปพร้อมกัน (ราคา/RS/breadth/ฯลฯ)
--------------------------------------------------------------------------------

ปุ่ม/คำสั่งข้างบนทำ "เฉพาะงบการเงิน" เท่านั้น
ถ้าจะ bake ไฟล์ data/*.json อื่นให้สดด้วย ก่อน push :
      python run_static_update.py
(ดูรายละเอียดใน  คู่มือ-อัพเดทข้อมูล.txt  ส่วนที่ 6)
financials_quarterly.json ก็จะถูก bake ในรอบนี้เหมือนกัน (ไม่ต้องทำข้อ 2 ซ้ำ)


--------------------------------------------------------------------------------
 หมายเหตุทางเทคนิค
--------------------------------------------------------------------------------

- แหล่งข้อมูล = SET.or.th official (source 'set_qpl' ใน financials.db) เท่านั้น
  ไม่ใช้ Finnomena (ห้ามขึ้น GitHub ตามกฎ)
- ~1,075 หุ้นมีข้อมูล · REIT / กองทุนอสังหา / หุ้นเข้าใหม่ บางตัวไม่มีงบ P&L
  รูปแบบมาตรฐาน → เว็บมือถือไม่แสดง section นั้น (ไม่ error)
- ค่าในไฟล์เก็บเป็น "ล้านบาท" (unit: "M฿") — เว็บคูณกลับก่อนแสดง
- ไฟล์ถูก re-bake อัตโนมัติจาก : ปุ่ม Data Health "🔄 อัพเดทงบการเงินทั้งหมด",
  ปุ่ม "ดึงเฉพาะที่ขาด/เก่า", คำสั่ง update_financials.py, run_static_update.py
