ทำความรู้จักโปรแกรม

SET Dashboard คือโปรแกรมสำหรับ วิเคราะห์ภาพรวมตลาดหุ้นไทย ช่วยให้คุณเห็นข้อมูลสำคัญในหน้าเดียว ไม่ว่าจะเป็น:

  • ภาพรวมตลาด — กี่ % ของหุ้นทั้งหมดกำลังขึ้น
  • กลุ่มอุตสาหกรรมไหนแข็งแกร่งที่สุด
  • หุ้นที่กำลัง Breakout หรือทำ New High
  • กรองหุ้นตามเงื่อนไขที่กำหนดเอง
  • ติดตามหุ้นที่สนใจใน Watchlist
โปรแกรมนี้เหมาะสำหรับ: นักลงทุนที่ต้องการ Top-Down Analysis — มองภาพใหญ่ก่อน แล้วค่อยลงมาหาหุ้นเดี่ยว

ไฟล์ที่จำเป็น

โฟลเดอร์ SET_Dashboard ต้องมีไฟล์เหล่านี้ครบก่อนเปิดใช้งาน

ไฟล์หลัก (ต้องมีก่อนรัน)

ไฟล์หน้าที่หมายเหตุ

set_data_fetcher.pyโค้ดดาวน์โหลดข้อมูลหุ้นจาก Yahoo Financeอย่าลบหรือเปลี่ยนชื่อ
set_dashboard.htmlหน้าเว็บ Dashboard ทั้งหมดอย่าลบหรือเปลี่ยนชื่อ
listedCompanies_en_US.xlsxรายชื่อหุ้น SET ทั้งหมด (โหลดจาก set.or.th)ต้องมีก่อน Refresh ครั้งแรก
requirements.txtรายการ Python library ที่ต้องติดตั้งstart.bat ใช้ไฟล์นี้ติดตั้ง library อัตโนมัติ

ไฟล์ที่โปรแกรมสร้างเอง (ไม่ต้องเตรียม)

ไฟล์ขนาดโดยประมาณสร้างเมื่อ
set_data.json~5–8 MBหลัง Full Refresh หรือ Quick Update ครั้งแรก — เก็บข้อมูล metrics หุ้นทุกตัว (RS, EMA, Returns, ATH ฯลฯ)
set_history.json~60–90 MBหลัง Full Refresh ครั้งแรก — เก็บประวัติราคา+ปริมาณซื้อขายย้อนหลัง ใช้วาดกราฟ 5Y/Max และคำนวณ EMA200 แม่นยำ

อัปเดตรายชื่อหุ้นใหม่: ถ้ามีหุ้น IPO ใหม่ หรือหุ้นถูก Delist ให้โหลดไฟล์ใหม่จาก set.or.th → ตลาดทุน → หลักทรัพย์ → ค้นหาหลักทรัพย์ → Download แล้วแทนที่ไฟล์ listedCompanies_en_US.xlsx จากนั้นกด Full Refresh

ต้องการ: Windows 10/11  ·  Python 3.10 ขึ้นไป  ·  Internet

1

2

ติ๊ก "Add Python to PATH" ก่อนกด Install

ช็อตสำคัญที่สุด — ถ้าไม่ติ๊ก โปรแกรมจะหาไม่เจอ Python ในภายหลัง

3

กด Install Now รอจนเสร็จ

ตรวจสอบโดยเปิด Command Prompt แล้วพิมพ์ python --version ถ้าขึ้นเลขเวอร์ชัน = สำเร็จ

ขั้นตอนที่ 2 — วางไฟล์โปรแกรม

คัดลอกโฟลเดอร์ SET_Dashboard ไปไว้ที่ไหนก็ได้ เช่น C:\SET_Dashboard\ หรือ Desktop

ตรวจสอบว่าไฟล์ครบ (ดูหัวข้อ ไฟล์ที่จำเป็น ด้านบน)

อย่าวางในโฟลเดอร์ที่มีชื่อภาษาไทยหรือ path ยาวผิดปกติ เช่น C:\Users\ชื่อภาษาไทย\ อาจทำให้ script error ได้

Browser เปิดขึ้นที่ localhost:5001

การอัปเดตข้อมูล

โปรแกรมมีปุ่มอัปเดต 2 แบบที่มุมบนขวา ใช้ต่างกันตามสถานการณ์:

ปุ่มใช้เมื่อระยะเวลาสิ่งที่ทำ
⚡ Quick Update ใช้ทุกวัน (หลังทำ Full Refresh ครั้งแรกแล้ว) ~2–5 นาที ดาวน์โหลดเฉพาะวันที่ขาดไป + recalculate metrics ทั้งหมด ครอบคลุม หุ้น SET/mai + ดัชนีกลุ่ม 30+ ดัชนี + DR/DRx ทุกตัว + NVDR Outstanding + Short Sales Daily Snapshot ในครั้งเดียว
⟳ Full Refresh ครั้งแรกที่ติดตั้ง หรือต้องการดึง Fundamentals ใหม่ (P/E, P/BV, Div) 20 นาที – 1.5 ชั่วโมง ดาวน์โหลด history ใหม่ทั้งหมดตามช่วงที่เลือก + Fundamentals ทุกตัว และดาวน์โหลดข้อมูล DR/DRx ทั้งหมดพร้อมกันอัตโนมัติ
ลำดับการใช้ครั้งแรก: ต้องกด ⟳ Full Refresh ก่อนเสมอ เพื่อสร้าง set_history.json (ไฟล์เก็บประวัติราคา) หลังจากนั้นกด ⚡ Quick Update ทุกวันได้เลย ไม่ต้อง Full Refresh อีก

เลือก Period สำหรับ Full Refresh

เมื่อกด ⟳ Full Refresh จะมีหน้าต่างให้เลือก ช่วงเวลาที่ต้องการดาวน์โหลด

Periodประวัติที่ได้เวลาโดยประมาณแนะนำสำหรับ
2Yย้อนหลัง 2 ปี~20–30 นาทีเครื่องที่ต้องการประหยัดเวลา / ทดสอบ
5Yย้อนหลัง 5 ปี~30–45 นาทีใช้งานทั่วไป กราฟ 5Y จะมีข้อมูลครบ
10Yย้อนหลัง 10 ปี~45–60 นาทีต้องการดู EMA200 แม่นยำสูง
Maxตั้งแต่ IPO (สูงสุดถึงปี 2001)~1–1.5 ชั่วโมงข้อมูลสมบูรณ์ที่สุด ATH แม่นยำที่สุด
แนะนำ Max สำหรับครั้งแรก — ได้ประวัติยาวที่สุด EMA200 แม่นยำที่สุด และ ATH (All-Time High) ถูกต้อง 100% หลังจากนั้นใช้ Quick Update ทุกวันแทน

คำศัพท์สำคัญ

ก่อนใช้งานควรทำความเข้าใจคำศัพท์พื้นฐานเหล่านี้ก่อนครับ

RS Score (Relative Strength Score)
คะแนน 0–99 วัดว่าหุ้นตัวนี้ แข็งแกร่งกว่าตลาดแค่ไหน คำนวณจากผลตอบแทนย้อนหลังหลายช่วงเวลาเทียบกับหุ้นทั้งหมดใน SET

80–99 แข็งแกร่งมาก (Top 20% ของตลาด)   50–79 ปานกลาง   0–49 อ่อนแอกว่าตลาด
RS Score = Rank percentile ของ (1M×2 + 3M×1 + 6M×1 + 1Y×1)
EMA (Exponential Moving Average)
ค่าเฉลี่ยราคาย้อนหลังแบบถ่วงน้ำหนัก ใช้ดูแนวโน้ม

EMA 20 = แนวโน้มระยะสั้น (ประมาณ 1 เดือน)
EMA 50 = แนวโน้มระยะกลาง (ประมาณ 2.5 เดือน)
EMA 200 = แนวโน้มระยะยาว (ประมาณ 10 เดือน)

ราคา อยู่เหนือ EMA = แนวโน้มขาขึ้น / ราคา อยู่ใต้ EMA = แนวโน้มขาลง
52W High / 52W Low
ราคาสูงสุดและต่ำสุดในช่วง 52 สัปดาห์ (1 ปี) ที่ผ่านมา

หุ้นที่ราคา ทำ 52W High ใหม่ = กำลังอยู่ในแนวโน้มขาขึ้นแข็งแกร่ง
หุ้นที่ราคา ใกล้ 52W Low = อาจเป็นโอกาสถ้าสัญญาณกลับตัวชัดเจน
Market Breadth
วัดว่ามีหุ้นกี่ % ที่ราคาอยู่เหนือเส้น EMA ต่างๆ

ถ้า % สูง เช่น 70% อยู่เหนือ EMA50 = ตลาดโดยรวมอยู่ในแนวโน้มขาขึ้น
ถ้า % ต่ำ เช่น 30% อยู่เหนือ EMA50 = ตลาดโดยรวมอ่อนแอ
Sec.Rank (Sector Rank)
อันดับของหุ้นในกลุ่ม sector เดียวกัน เรียงจาก RS Score สูงสุด

เช่น 2/15 = อันดับ 2 จาก 15 หุ้นในกลุ่มเดียวกัน

อันดับ 1–25% หุ้นแข็งแกร่งในกลุ่ม   25–50% ปานกลาง   >50% อ่อนกว่าครึ่งกลุ่ม
P/E (Price to Earnings)
อัตราส่วนราคาต่อกำไร — ตลาดยินดีจ่ายกี่เท่าของกำไรต่อปี

< 15x ถูก   15–25x ปานกลาง   > 25x แพง (หรือกำไรต่ำมาก)
P/BV (Price to Book Value)
อัตราส่วนราคาต่อมูลค่าทางบัญชี — ตลาดยินดีจ่ายกี่เท่าของสินทรัพย์สุทธิ

< 1x ซื้อได้ต่ำกว่ามูลค่าทางบัญชี   1–2x ปานกลาง   > 2x แพงกว่ามูลค่าบัญชี
Dividend Yield (อัตราผลตอบแทนเงินปันผล)
ปันผลที่ได้รับต่อปี คิดเป็น % ของราคาหุ้นปัจจุบัน

≥ 4% ปันผลสูง   2–4% ปานกลาง   < 2% ต่ำ
RVOL (Relative Volume — ปริมาณซื้อขายสัมพัทธ์)
วัดว่าวันนี้มีปริมาณซื้อขาย มากหรือน้อยกว่าค่าเฉลี่ย 20 วันกี่ %

> 200% ปริมาณสูงผิดปกติ (มักเกิดเมื่อมีข่าวหรือ Breakout)   100–200% สูงกว่าปกติ   < 100% ต่ำกว่าค่าเฉลี่ย
RVOL = (Volume วันนี้ / ค่าเฉลี่ย Volume 20 วัน) × 100
ATH (All-Time High — ราคาสูงสุดตลอดกาล)
ราคาสูงสุดของหุ้นตัวนั้นตลอดช่วงเวลาที่มีข้อมูล (สูงสุดถึงปี 2001)

ATH% = ระยะห่างจาก ATH เป็นเปอร์เซ็นต์ ค่าติดลบเสมอ (เว้นแต่กำลังทำ ATH ใหม่)

Rotation — การหมุนเวียนของกลุ่มหุ้น

แสดงการเคลื่อนไหวของ กลุ่มอุตสาหกรรม ในรูปแบบ Scatter Plot โดยเปรียบเทียบ:

  • แกน X = ผลตอบแทน 3 เดือน (Trend) — แสดงช่วง −30% ถึง +60%
  • แกน Y = ผลตอบแทน 1 เดือน (Momentum) — แสดงช่วง −30% ถึง +60%
  • ใช้ Symlog Scale — ค่าใกล้ 0% มีสเกลเชิงเส้น ค่าสูงมากถูก compress ให้อ่านง่าย ไม่ถูก outlier ดึงสเกล
  • Bubble ที่อยู่ใกล้กันมากจะ ถูกเลื่อนแยกออกอัตโนมัติ เพื่อไม่ให้ซ้อนกัน (แต่ยังอยู่ใกล้ตำแหน่งจริง)

บนซ้ายImproving — กำลังฟื้นระยะสั้นดี แต่ยังตามหลังระยะยาว — อาจกำลังกลับตัว

Stage Analysis — Weinstein Stages

จัดหุ้นทุกตัวใน SET เป็น 4 Stage ตามแนวคิดของ Stan Weinstein — ใช้ EMA200 และ Slope เป็นเกณฑ์หลัก

นิยาม Stage ทั้ง 4

Stageชื่อความหมายเงื่อนไข
Stage 2 Advancing โซนซื้อ — ราคาขึ้น + EMA200 เอียงขึ้น ราคา > EMA200 และ EMA200 slope ≥ +1.5%
Stage 1 Basing สะสมฐาน — รอ Breakout ราคา < EMA200 และ EMA200 slope ≥ −1.5%
Stage 3 Topping ยอดเขา — Momentum เริ่มอ่อน ราคา > EMA200 และ EMA200 slope < +1.5%
Stage 4 Declining ขาลง — หลีกเลี่ยง ราคา < EMA200 และ EMA200 slope < −1.5%

AVG ถึง +1SDส้มสูงกว่าค่าเฉลี่ย — Fair Value ค่อนข้างแพง
+1SD ถึง +2SDแดงอ่อนOvervalued — แพงกว่าค่าเฉลี่ย
สูงกว่า +2SDแดงเข้มOvervalued มาก — แพงผิดปกติ ควรระวัง
หมายเหตุ: SD Band วัดความถูก/แพง เทียบกับตัวเองในอดีต ไม่ใช่เทียบกับหุ้นตัวอื่น หุ้นที่ปกติ P/E สูง (เช่น Growth Stock) อาจอยู่ใกล้ AVG แม้ P/E จะสูงกว่าตลาด
วิธีใช้ร่วมกับ RS Score: หุ้นที่ Valuation อยู่ใต้ AVG + RS Score ≥ 60 = โอกาสที่น่าสนใจ เพราะทั้งถูกและเริ่มมี Momentum ขึ้น

หลักการ: หุ้นปันผลสูงที่ RS ดีด้วย = ได้ทั้ง Passive Income และ Capital Gain — ดีกว่าเลือกแค่ปันผลสูงอย่างเดียวซึ่งอาจเป็นหุ้นที่ราคาตกนาน

คำถามที่พบบ่อย

ต้องกด Full Refresh บ่อยแค่ไหน?

กด Full Refresh ครั้งแรกครั้งเดียว เพื่อสร้าง set_history.json หลังจากนั้นใช้ ⚡ Quick Update ทุกวันได้เลย Full Refresh อีกครั้งก็ต่อเมื่อต้องการอัปเดต Fundamentals (P/E, P/BV, Div Yield) ซึ่งไม่ค่อยเปลี่ยนบ่อย (แนะนำ ~ทุก 1 เดือน)

ATH% คำนวณจากข้อมูลย้อนหลังถึงเมื่อไหร่?

ATH คำนวณจาก ราคาสูงสุดทั้งหมดใน set_history.json ถ้า Full Refresh ด้วย period Max จะย้อนหลังได้ถึงปี 2001 ถ้า period 2Y จะ ATH แม่นเฉพาะ 2 ปีล่าสุด แนะนำ Full Refresh ด้วย Max เพื่อ ATH ที่แม่นยำ

เลือก Period อะไรดีสำหรับ Full Refresh?

ถ้า internet เร็วและมีเวลา: เลือก Max ได้ ATH ที่แม่นยำ + EMA200 ดีที่สุด ถ้าต้องการรวดเร็ว: เลือก 5Y ยังได้ข้อมูลที่ดีพอสำหรับใช้งานทั่วไป

ข้อมูลอัปเดตถึงวันไหน?

ดูได้ที่มุมบนขวา "อัปเดต: YYYY-MM-DD HH:MM" — ข้อมูลจะใหม่เท่ากับครั้งล่าสุดที่กด Quick Update หรือ Full Refresh

Quick Update แล้ว error ทำไม?

Yahoo Finance มีการ rate limit — กดช่วง 14:30–17:30 น. (Yahoo กำลัง sync) แก้ไขโดยรอ 30 นาทีแล้วลองใหม่ ข้อมูลเดิมยังแสดงอยู่ระหว่างรอ

ทำไม P/E บางหุ้นแสดงเป็น —?

หุ้นที่ขาดทุน (กำไรติดลบ) P/E จะแสดงเป็น N/A สีแดง ถ้าแสดงเป็น — หมายความว่า Yahoo Finance ไม่มีข้อมูล (พบบ่อยในหุ้นขนาดเล็กหรือ REIT)

RS Score คำนวณยังไง?

คำนวณจากผลตอบแทน 1M×2 + 3M×1 + 6M×1 + 1Y×1 แล้ว Rank เป็น Percentile ในกลุ่มหุ้นทั้งหมด คะแนน 99 = ดีที่สุด 1% ของตลาด

EMA200 ในกราฟ Max ใช้ข้อมูลย้อนหลังนานแค่ไหน?

ใช้ประวัติราคาตั้งแต่ที่ yfinance มีให้ — สำหรับหุ้น SET ส่วนใหญ่ย้อนหลังได้ถึง ปี 2001-2004 (ประมาณ 20+ ปี) EMA200 จึงแม่นยำมากเพราะมี Warmup period เพียงพอ

Val. Band ดึงข้อมูลจากไหน?

ดึงจาก mrlikestock.com ครั้งแรกที่ค้นหา แล้ว Cache ไว้ 6 ชั่วโมง ในหน่วยความจำ Server การค้นหาครั้งต่อไปภายใน 6 ชั่วโมงจะโหลดจาก Cache ทันที ไม่ต้องรอ ถ้า Cache หมดอายุหรือ restart server จะดึงข้อมูลใหม่จาก mrlikestock.com อีกครั้ง

Watchlist หายหลังเปิด Browser ใหม่?

Watchlist เก็บใน localStorage ของ Browser — ถ้าล้าง Cache หรือเปิด Incognito จะหาย แนะนำใช้ Browser เดิมเสมอ

เปิดจากคอมพิวเตอร์เครื่องอื่นในบ้านได้ไหม?

ได้ครับ เปิดจากเครื่องที่รัน start.bat แล้วเข้าเว็บด้วย IP ของเครื่องนั้น เช่น http://192.168.1.x:5001

Badge N (NVDR) ไม่แสดงในตาราง หุ้นทั้งหมด?

Badge N จะแสดงหลังโหลดข้อมูล NVDR เสร็จ (โหลด background อัตโนมัติ) ถ้ายังไม่แสดง ลอง Quick Update เพื่อดึงข้อมูล NVDR ใหม่ — Badge N แสดงเฉพาะหุ้นที่ NVDR ≥ 5%

Short Sales ไม่มีข้อมูล?

ต้องนำเข้าข้อมูลก่อน: โหลด Excel จาก SET.or.th → Short Sales → Download แล้วรัน python import_short_sales.py หลังจากนั้น Quick Update จะอัปเดต Daily Snapshot เองอัตโนมัติ

Squeeze Radar ว่างเปล่า?

Squeeze Radar ต้องการ 2 เงื่อนไข: Short Position > 1% (มาจากไฟล์ Excel) และ Insider ซื้อสะสม (มาจากหน้า Insider) — ต้องโหลดหน้า Insider ก่อน แล้วกลับมาดู Short อีกครั้ง

ปุ่ม 🌐 SET ใน Chart Modal ไปที่ไหน?

เปิดหน้า Company Highlights / งบการเงิน บนเว็บ SET.or.th โดยตรง URL จะเปลี่ยนตามชื่อหุ้นที่เปิดอัตโนมัติ เช่น set.or.th/th/market/product/stock/quote/KBANK/financial-statement/company-highlights

ไฟล์ set_history.json ใหญ่มาก ปกติไหม?

ปกติครับ ไฟล์นี้เก็บประวัติราคา + ปริมาณซื้อขายของหุ้น ~900 ตัว ย้อนหลัง 20+ ปี ขนาดประมาณ 60–90 MB ไม่ได้โหลดใน browser จึงไม่กระทบความเร็วของ Dashboard

ข้อมูล DR/DRx อัปเดตพร้อมกับหุ้น SET ไหม?

ใช่ครับ — ⚡ Quick Update ครอบคลุม DR/DRx ทุกตัวพร้อมกับหุ้น SET และดัชนีกลุ่มในครั้งเดียว ไม่ต้องกดปุ่มแยก

ราคา DR บน SET กับราคาที่เห็นในหน้า DR ต่างกัน?

ปกติครับ หน้า DR แสดงราคา Underlying Stock ในสกุลเงินต้นทาง (USD, HKD ฯลฯ) ไม่ใช่ราคา DR ที่เทรดบน SET ราคา DR บน SET มีทั้ง Premium และ Discount จาก Underlying ขึ้นอยู่กับ Supply/Demand และ FX

TTM ในงบการเงินคืออะไร และทำไมบางตัวแสดง —?

TTM (Trailing 12 Months) คือผลรวม 4 ไตรมาสล่าสุด ทำให้เห็นผลประกอบการปัจจุบันที่อัปเดตกว่างบปีล่าสุด บางครั้งข้อมูล quarterly จาก yfinance มี quarter ขาดหายไป (เช่น Q3 หายไป ระบบจะเลือก quarter ผิดชุดและได้ผลรวมผิด) ระบบจะตรวจพบและแสดง — แทนที่จะแสดงตัวเลขผิด ซึ่งดีกว่าการแสดงค่าเกินจริงหลายเท่า เช่น PTTEP อาจผิดได้ถึง 3,000%

งบการเงินใน Chart Modal แสดงกี่ปี?

แสดง 4 ปีล่าสุดเสมอ ไม่ว่าจะอยู่ในปีไหน เมื่องบปีใหม่ออกมา ปีเก่าที่สุดจะหลุดออกอัตโนมัติ ไม่ต้องอัปเดต Dashboard

Golden Cross คืออะไร?

Golden Cross คือสภาวะที่ EMA50 > EMA200 ในขณะนี้ — แสดงว่าโครงสร้างราคาระยะกลางแข็งแกร่งกว่าระยะยาว (Bull Market State) Filter นี้ไม่ได้หา "จุดที่ EMA50 ตัดขึ้น" แต่กรองหุ้นที่ยังคงอยู่ในสภาวะ Golden Cross

RVOL คืออะไร?

RVOL (Relative Volume) คือ Volume วันนี้ ÷ เฉลี่ย 20 วัน × 100 — >200% = Volume สูงกว่าปกติ 2 เท่า มักเกิดเมื่อมีข่าวหรือ Breakout 100–200% = สูงกว่าปกติ <100% = ต่ำกว่าค่าเฉลี่ย

ระบบแจ้งเตือนราคาทำงานอยู่ไหมถ้าไม่ได้เปิดแผง 🔔?

ทำงานอยู่ครับ ระบบเช็คราคาใน background ทุก 5 นาที ไม่ว่าแผงจะเปิดหรือปิด — ถ้าถูกกระตุ้นจะมี Popup ขึ้นมาอัตโนมัติ

เพิ่ม DR ใน Watchlist แล้วขึ้น "ไม่พบข้อมูล"?

หน้า Watchlist จะโหลดข้อมูล DR อัตโนมัติเมื่อพบว่ามีหุ้น DR อยู่ในรายการ รอสักครู่จะแสดงผลเอง ถ้ายังไม่ขึ้นให้ลอง Refresh หน้า Browser ครั้งเดียว

ปุ่ม Stage ในหน้าหุ้นทั้งหมดทำงานยังไง?

กดปุ่ม Stage ที่แถวกรอง (Stage 1/2/3/4) เพื่อกรองให้เหลือเฉพาะหุ้นใน Stage นั้น — กด "ทั้งหมด" เพื่อยกเลิก Hover บนปุ่มจะเห็น Tooltip อธิบายเกณฑ์ของแต่ละ Stage

แจ้งเตือนราคาทำงานได้แม่นยำแค่ไหน?

ความแม่นยำขึ้นอยู่กับว่า Quick Update ครั้งล่าสุดเป็นเมื่อไหร่ ราคาในระบบ = ราคาปิดของวันล่าสุดที่ดึงข้อมูลมา ไม่ใช่ราคา Real-Time แนะนำ Quick Update ทุกวันหลังตลาดปิด (หลัง 17:30 น.) เพื่อให้ราคาในระบบเป็นปัจจุบัน
