====================================================
  SET Dashboard — ไฟล์ที่ต้องก็อปไปด้วยเวลาย้ายเครื่อง
  (อัปเดต 2026-07-24 — หลังเพิ่ม US/HK/JP Index pipeline, Hedge Holdings (13F),
   Delisted Log, S50 Flow, Bond Flow, folder data/ แยกไฟล์ตลาดต่างประเทศ)

[ จำเป็นต้องมี — โค้ด ก็อปทุกไฟล์/โฟลเดอร์นี้ ]

  start.bat                    ← ดับเบิ้ลคลิกเปิดโปรแกรม
  app.py                       ← Flask Web Server (หัวใจหลัก)
  set_data_fetcher.py          ← โค้ดดาวน์โหลดข้อมูลจาก Yahoo Finance
  set_dashboard.html           ← โครง HTML ของหน้าเว็บ
  requirements.txt             ← รายการ Library ที่ต้องติดตั้ง
  index.html                   ← redirect เข้า set_dashboard.html
  manifest.json, sw.js         ← PWA manifest + service worker
  listedCompanies_en_US.xls    ← รายชื่อหุ้น SET (ดาวน์โหลดจาก set.or.th — นามสกุล .xls
                                  จริงๆ ไม่ใช่ .xlsx ดึงตรงจาก set.or.th แบบนี้เสมอ)

  core/                        ← metrics.py (สูตร RS/EMA), store.py/store_factory.py (persistence),
                                  hk_store.py/jp_store.py/us_store.py (store ตลาดต่างประเทศ),
                                  delisted_log.py, run_log.py
  sources/                     ← yahoo.py, tradingview.py, sec.py, sec_store.py, set_api.py,
                                  dr_universe.py, dr_descriptions.py, financials_store.py,
                                  factor_snapshot.py, flow_signals.py, dividend_stats.py,
                                  set_daily_valuation.py, mirror_ondemand.py, price_analytics.py,
                                  index_metrics_common.py, dataroma.py (Hedge Holdings 13F scraper),
                                  hk_index_membership.py, hk_index_metrics.py,
                                  jp_index_membership.py, jp_index_metrics.py,
                                  us_index_membership.py, us_index_metrics.py
  services/                    ← refresh.py (orchestration), breadth.py (market breadth),
                                  rotation.py (rotation alert state)
  static/                      ← dashboard.css, dashboard.js, fin_translations.js, icons/

[ ข้อมูลที่ดาวน์โหลดแล้ว (root) — ก็อปด้วยถ้าไม่อยากรอ Full Refresh ใหม่ (~1-2 ชม.) ]

  set_prices.db          ← ราคาย้อนหลังหุ้นไทยทุกตัว (SQLite) — แหล่งหลักของ Breadth/Market
                            Internals/สถิติระยะยาว/Backtest ~320 MB
  set_history.json       ← ประวัติราคาย้อนหลัง (ใช้กราฟ 5Y/Max + EMA200) ~95 MB
  set_data.json          ← ข้อมูลหุ้นทุกตัว (ราคา, RS, EMA, Fundamentals) ~12 MB
  set_data_backup.json   ← backup อัตโนมัติของ set_data.json — app.py fallback มาอ่านไฟล์นี้
                            เองถ้าไฟล์หลักเสียหาย (ดู app.py: BACKUP_FILE) ไม่บังคับต้องก็อป
                            (จะสร้างใหม่เองรอบถัดไปที่ระบบเซฟข้อมูล) แต่ถ้าก็อปไปด้วยจะกัน
                            เคส "ไฟล์หลักพังทันทีที่เปิดเครื่องใหม่แล้วยังไม่มี backup"
  dr_cache.json          ← ข้อมูล DR/DRx ต่างประเทศ ~40 MB
  dr_descriptions.json   ← คำอธิบายบริษัท (EN+แปลไทย) หุ้นไทย+DR ~4 MB (อนุญาต push GitHub ได้)
  indices_cache.json     ← ข้อมูลดัชนีกลุ่ม 30+ ดัชนี ~5 MB
  nvdr_data.json         ← ข้อมูล NVDR (ต่างชาติถือครอง)
  short_sales_data.json  ← ข้อมูล Short Sales
  set_market_stats.json  ← สถิติ PE/PBV ตลาดรวม
  market_flow_data.json  ← ข้อมูล flow signals (Confluence page)
  s50_flow_data.json     ← ข้อมูล flow S50 Futures
  bond_flow_data.json    ← ข้อมูล flow ตลาดพันธบัตรไทย
  delisted_log.json      ← ประวัติหุ้นที่ถูกเพิกถอน (กันตกหล่นตอนคำนวณ Breadth ย้อนหลัง)
  rotation_state.json    ← state ของ Rotation alert (กลุ่มไหนแจ้งเตือนไปแล้ว)
  mirror_names.json      ← ชื่อ mirror (ชื่อไทย/อังกฤษ) สำหรับหุ้นต่างประเทศที่มี DR
  dr_universe_auto.json  ← universe DR/DRx ที่ระบบ auto-detect
  backtest_screener_results_TH.json, backtest_screener_results_US.json ← ผล backtest cache
  Table_PE.xls           ← ข้อมูล valuation อ้างอิงราย sector (manual — ดูข้อ 15 ในคู่มือติดตั้ง.md)
  Table_PBV.xls          ← ข้อมูล valuation อ้างอิงราย sector (manual)

  ** ถ้าไม่ก็อปไฟล์ข้อมูล → ต้อง Full Refresh ใหม่ในเครื่องใหม่ (~1-2 ชั่วโมง)

[ ขั้นตอนหลังก็อปไปเครื่องใหม่ ]

  1. วางทั้งโฟลเดอร์ไว้ที่ไหนก็ได้ในเครื่องใหม่ (ต้องก็อป core/ sources/ services/ static/ data/
     ไปพร้อมกันด้วย ไม่งั้น app.py จะ import ไม่เจอ หรือหน้า US/HK/JP/Hedge Holdings ว่างเปล่า)
  2. ตรวจสอบว่าติดตั้ง Python 3.10+ แล้ว
     → โหลดที่ python.org (ติ๊ก "Add to PATH" ตอนติดตั้ง)
  3. ดับเบิ้ลคลิก start.bat
     → จะติดตั้ง Library อัตโนมัติครั้งแรกจาก requirements.txt
       (flask, yfinance, pandas, openpyxl, xlrd, tqdm, waitress, requests,
        websocket-client, lxml, deep-translator)
  4. Browser เปิดขึ้นเองที่ http://localhost:5001
  5. ถ้าไม่ได้ก็อปไฟล์ข้อมูล (root) → กด Full Refresh เพื่อดาวน์โหลดใหม่
  6. ถ้าไม่ได้ก็อป financials.db → หน้า Screener+/งบการเงินจะว่าง ต้องกด
     "🔄 อัพเดทงบการเงินทั้งหมด" ในหน้างบการเงินใหม่ (ใช้เวลานาน — เป็นชั่วโมง)
  7. ถ้าไม่ได้ก็อป us_prices.db/hk_prices.db/jp_prices.db → หน้าหุ้น US/HK/JP จะว่าง
     ต้องรัน backfill_us_index_prices.py / backfill_hk_index_prices.py /
     backfill_jp_index_prices.py ใหม่ (ใช้เวลานาน)
  8. ถ้าไม่ได้ก็อปโฟลเดอร์ data/ → หน้า US/HK/JP, Insider, Hedge Holdings (13F) จะว่าง
     จนกว่าจะกด Refresh ที่หน้านั้นๆ ใหม่
