PROMPT 2 — เพิ่ม preset หาหุ้นดี US/HK ใน Screener+ (งานถัดไป)
############################################################

เพิ่ม preset "หาหุ้นดี US/HK" ในหน้า Screener+ (Fundamental Screener) ของโปรเจกต์ SET Dashboard นี้ ให้กดปุ่มเดียวหาหุ้นคุณภาพราคาถูกในตลาด US และ HK ได้เลย

== บริบท ==
- หน้า Screener+ = page-fscreener · โค้ดอยู่ static/dashboard.js (config-driven)
  * FS_FILTERS = นิยาม filter (key/label/unit/cmp gte|lte|bool/tip)
  * FS_PRESETS = สูตรสำเร็จ (โครงเดิม: { name, color, desc, set:{key:value}, bool:[key] })
  * applyFsPreset(i) = เคลียร์แล้วเติมค่า preset ลง input แล้วค้นหา
  * universe selector id=fs-universe (ค่า: all/th/dr/us/hk) · US/HK กรองฝั่ง server
    (/api/factor-screener?universe=us|hk) ส่งกลับ ≤500 · _fsApplyUniverseUI() ปิด
    (ทำจาง+disable) ฟิลด์กลุ่ม FS_YAHOO_ONLY อัตโนมัติเมื่อเลือก US/HK
- ข้อมูล US/HK มาจากตาราง factor_snapshot_mirror (Finnomena 16 ปี, ~4,371 US + 1,199 HK)

== ผลที่ยืนยันแล้วจากข้อมูลจริง (สำคัญ — อย่าเปลี่ยน logic นี้) ==
- Factor ที่ US/HK "มี" (Finnomena): roe, roa, net_margin, gross_margin, ocf_ni_ratio,
  profit_yoy_q, rev_yoy_q, profit_accel_streak, qoq/margin streak, ttm_margin_delta,
  pe_value, pbv_value, ps_value, div_yield, season_swing, entering_high_season, quarters_available
- Factor ที่ US/HK "ไม่มี" (Yahoo-only = None): rev_cagr, growth_percentile, profit_streak,
  rule_of_40, cash_cycle, net_cash_positive, buyback, goodwill_ratio, ocf_neg_years,
  interest_coverage, dividend_coverage  (มี FS_YAHOO_ONLY ครอบอยู่แล้ว)
- **US มี pe/pbv/ps percentile (ใช้ได้)** แต่ **HK มี percentile = 0 ตัว** (Finnomena ให้
  PE ของ HK ย้อนสั้น <12 งวด คำนวณ percentile ไม่ได้) → **HK ต้องใช้ค่าสัมบูรณ์ (pe_value/pbv_value)
  แทน percentile** ห้ามใช้ pe_percentile กับ preset HK (จะได้ 0 ผลลัพธ์)
- ทดลองสกรีน HK 4 แนวเทียบกันแล้ว (Quality ล้วน / Quality+ปันผล / ต่ำกว่า Book / GARP 2 ชั้น):
  * Quality ล้วนไม่กรอง valuation → ได้หุ้นแพง + ติด net_margin เพี้ยน (เคยเจอ 6089%)
  * Dividend yield สูงมาก (20-45%) มักเป็นปันผลพิเศษครั้งเดียว ไม่ยั่งยืน
  * PBV ต่ำมากอย่างเดียว (<0.2) เป็น value trap ชัด (กลุ่มหุ้นการศึกษาจีนที่โดนกฎเกณฑ์รัฐกระทบ)
  * **GARP 2 ชั้น (PE ต่ำ + PBV ต่ำ พร้อมกัน + ROE/กำไรโต) ให้ผลสะอาดสุด** — สองด่านหักล้าง
    จุดอ่อนกันเอง (PE เดี่ยวโดนกำไรพิเศษหลอกได้, PBV เดี่ยวเจอ value trap ได้)
  * ข้อมูล Finnomena HK มี outlier จริง (net_margin, div_yield เคยเจอค่าเพี้ยนหลักพัน/หลักสิบเปอร์เซ็นต์)
    ต้อง cap ทั้งขอบบนและล่างของ roe/net_margin ไม่ใช่แค่ ≥ อย่างเดียว

== สิ่งที่ต้องทำ ==

1) เพิ่มความสามารถ "filter แบบช่วง (min–max)" ให้ FS_FILTERS
   ตอนนี้ filter รองรับทิศทางเดียว (≥ หรือ ≤) ต้องขยายให้ filter บางตัวมีได้ทั้งขอบบนและล่าง
   พร้อมกัน (เช่น roe ระหว่าง 15-80, net_margin ระหว่าง 5-60) โดยไม่กระทบ filter เดิมที่ใช้
   ทิศทางเดียวอยู่ (ต้อง backward-compatible กับ preset เก่าทั้งหมด)

2) เพิ่ม 2 preset ใน FS_PRESETS (static/dashboard.js):

   preset A — ชื่อ "🇺🇸 US หุ้นดีราคาถูก" (color '#58a6ff', universe:'us')
     desc: "คุณภาพ+เติบโต+ถูกเทียบอดีต (US)"
     set: { roe:15, net_margin:10, ocf_ni_ratio:0.8, profit_yoy_q:15,
            profit_accel_streak:1, pe_percentile:50, quarters_available:20 }
     (ทุกตัวเป็น ≥ เดี่ยว ยกเว้น pe_percentile ที่เป็น ≤)

   preset B — ชื่อ "🇭🇰 HK หุ้นดีราคาถูก" (color '#e3b341', universe:'hk')
     desc: "GARP 2 ชั้น — PE&PBV ต่ำคู่กัน + คุณภาพ (HK percentile ใช้ไม่ได้)"
     set: {
       pe_value: {min:3, max:12},
       pbv_value: {min:0.3, max:1.5},
       roe: {min:15, max:80},
       net_margin: {min:5, max:60},
       ocf_ni_ratio: 1,        // >= เดี่ยว
       profit_yoy_q: 10,       // >= เดี่ยว
       quarters_available: 16  // >= เดี่ยว
     }
     (โครง set ด้านบนเป็นตัวอย่างเจตนา — ปรับให้ตรงกับรูปแบบ min-max ที่ทำจริงในข้อ 1 ได้)

3) ทำให้ preset สลับ universe อัตโนมัติ (UX): เพิ่ม field `universe` ในโครง preset (A -> 'us',
   B -> 'hk') แล้วแก้ applyFsPreset ให้ ถ้ามี p.universe: set ค่า dropdown fs-universe =
   p.universe ก่อน แล้วเรียก _fsApplyUniverseUI() (ปิดฟิลด์ Yahoo-only) ก่อน runFscreener()
   เพื่อให้กดปุ่มเดียวสลับตลาด+กรองครบ (preset เดิมที่ไม่มี universe ต้องทำงานเหมือนเดิม)

4) เพิ่ม tip/หมายเหตุสั้นๆ ใน preset B ว่าใช้ PE/PBV ค่าสัมบูรณ์เพราะ percentile ของ HK ใช้ไม่ได้
