--------------------------------------------------------------------------------
 ทุกวันที่เปิดแอป (หรือปล่อยผ่านไปก็ได้ ไม่กดก็ไม่พัง)
--------------------------------------------------------------------------------

  ⚡ Quick Update  (ปุ่มบนสุดของแอป)
  ทำอะไร: อัพเดทราคาล่าสุด, อันดับความแข็งแกร่งหุ้น (RS), ข่าวผู้บริหารซื้อขายหุ้น,
          หุ้น short, NVDR, เงินไหลเข้า-ออก
  ใช้เวลา: ไม่กี่นาที
  เปรียบเทียบ: เหมือนเปิดแอปข่าว/ไลน์ เพื่อดูว่ามีอะไรใหม่วันนี้บ้าง

  ถ้าเปิดแอปผ่านมือถือ/ไอแพด (เว็บ ไม่ใช่โปรแกรมในโน้ตบุ๊ค) — "ไม่ต้องกดอะไร
  เลย" ข้อมูลอัพเดทให้อัตโนมัติวันละ 3 รอบอยู่แล้ว (เช้า/บ่าย/เย็น)

--------------------------------------------------------------------------------
 เดือนละครั้ง
--------------------------------------------------------------------------------

  1) ⟳ Full Refresh  (ปุ่มบนสุดของแอป คู่กับ Quick Update)
     ทำอะไร: ดึงราคาย้อนหลังเต็ม 10 ปีใหม่ + อัพเดทค่า P/E, P/BV, มูลค่าบริษัท
             ให้ตรงปัจจุบัน
     ใช้เวลา: นานกว่า Quick Update พอสมควร (ปล่อยรันไปทำอย่างอื่นได้)
     ข้อควรรู้: ปุ่มนี้ "ไม่ได้" อัพเดทข่าวผู้บริหาร/หุ้น short/NVDR ให้ — ถ้า
     อยากได้ของพวกนั้นต้องกด Quick Update แยกต่างหาก (คนละหน้าที่กัน)

  2) หน้า "Valuation" — วางไฟล์ P/E P/BV ใหม่จาก SET
     ทำอะไร: อัพเดทค่า P/E เฉลี่ยตลาด/รายอุตสาหกรรมให้ทันเดือนล่าสุด
     วิธีทำ: โหลดไฟล์ Table_PE.xls + Table_PBV.xls จากเว็บ SET.or.th มาวางทับ
             ไฟล์เดิมในโฟลเดอร์โปรแกรม แล้วกดปุ่ม "⟳ อัพเดทข้อมูล P/E & P/BV"
             ในหน้า Valuation
     เตือนเอง: ถ้าเลยวันที่ 10 ของเดือนแล้วยังไม่อัพเดท แอปจะมีป้ายเตือนขึ้นเอง
             ไม่ต้องจำเอง

--------------------------------------------------------------------------------
 ไตรมาสละครั้ง (หลังบริษัทประกาศงบ ~ก.พ. / พ.ค. / ส.ค. / พ.ย.)
--------------------------------------------------------------------------------

  3) หน้า "งบการเงิน" ปุ่ม "🔄 อัพเดทงบการเงินทั้งหมด"  — สำหรับหุ้นไทย
     ทำอะไร: ดึงงบไตรมาสล่าสุดของหุ้นไทยทุกตัวมาเก็บไว้ในเครื่อง

  4) หน้า "DR/DRx" ปุ่ม "🔄 ดึงเฉพาะที่ขาด/เก่า (local)"  — สำหรับหุ้นต่างประเทศ
     ทำอะไร: เหมือนข้อ 3 แต่สำหรับหุ้นต่างประเทศ (DR) — ฉลาดพอที่จะข้ามตัวที่
             เพิ่งดึงไปแล้วเมื่อไม่นาน จึงเร็วกว่าปุ่ม "ดึงทั้งหมด" ด้านล่างมาก
     แนะนำ: ใช้ปุ่มนี้เป็นหลัก ไม่ต้องใช้ปุ่ม "📥 ดึงทั้งหมด" บ่อยๆ

     ทางลัด (สำหรับคนที่พอเปิด "cmd"/"terminal" ได้): แทนที่จะกดปุ่มข้อ 3+4
     ทีละหน้า สามารถรันคำสั่งเดียว python update_financials.py ให้ทำครบทุก
     ขั้นตอนอัตโนมัติ (ดูรายละเอียดส่วนที่ 5)

--------------------------------------------------------------------------------
 นานๆ ครั้ง / ทำเมื่อจำเป็นเท่านั้น
--------------------------------------------------------------------------------

  5) หน้า "DR/DRx" ปุ่ม "📥 ดึงทั้งหมด (local)"
     กดเมื่อไหร่: เฉพาะตอนสงสัยว่าตัวเลขบางตัวดูผิดปกติ/ค้าง หรือรู้ว่าบริษัท
     ไหนเพิ่งประกาศงบภายใน 7 วันที่ผ่านมา (ปุ่ม "เฉพาะที่ขาด/เก่า" ข้อ 4 จะยัง
     ไม่ดึงงวดใหม่ให้ถ้าเพิ่งดึงตัวนั้นไปเมื่อไม่ถึงสัปดาห์)
     ใช้เวลา: นานกว่าข้อ 4 มาก เพราะดึงหุ้นต่างประเทศทุกตัวใหม่หมด

  6) หน้า "DR/DRx" ปุ่ม "🔍 เช็คหุ้นใหม่/ถูกถอดจาก SET.or.th"
     กดเมื่อไหร่: เดือนละครั้งพอ เพื่อดูว่าตลาดหลักทรัพย์ออก DR ตัวใหม่มาไหม
     ปกติ: ขึ้นว่า "ไม่มีอะไรต้องอัปเดต" อยู่แล้วเป็นส่วนใหญ่ (ระบบเช็คให้เอง
     อัตโนมัติอยู่แล้วเวลาเปิดหน้า DR — ปุ่มนี้แค่เอาไว้ดูรายละเอียดเผื่ออยากรู้)

  7) หุ้นต่างประเทศทั้งตลาด (US/HK นอกพอร์ต ที่ใช้ในเมนู Screener+)
     ทำโดย: รันคำสั่ง python mirror_finnomena.py force (ดูส่วนที่ 5)
     ความถี่: ปีละ ~4 ครั้งพอ (ใช้เวลาหลายชั่วโมง แนะนำปล่อยรันตอนกลางคืน)

  8) หน้า "DR/DRx" ปุ่ม "📖 ดึงคำอธิบายบริษัท DR (local)"
     ทำอะไร: ดึง Description จาก Yahoo Finance + แปลไทยอัตโนมัติ ให้หุ้น DR
             ที่ยังไม่เคยดึง (ข้ามตัวที่ดึงไปแล้วไม่เกิน 180 วัน)
     กดเมื่อไหร่: ไม่บ่อย — ปกติระบบดึงให้เองอัตโนมัติทีละตัวตอนเปิดดูในเครื่อง
             (ดูรายละเอียด "เกี่ยวกับบริษัท" ในส่วนที่ 7) กดปุ่มนี้เฉพาะตอนอยาก
             ให้เว็บมือถือมีข้อมูลของหุ้นใหม่ด้วย (ต้อง bake+push ต่อ ดูส่วนที่ 7)

Dashboard นี้มีข้อมูล 3 กลุ่มใหญ่ อัพเดทคนละวิธี:

  (A) ข้อมูลราคา/เทคนิค/flow  — อัพเดทอัตโนมัติ (GitHub Actions) + ปุ่มในแอป
  (B) P/E & P/BV ของตลาด      — อัพเดทเองด้วยมือ (ไฟล์ Excel จาก SET)
  (C) งบการเงิน (Yahoo/SET/Finnomena) — อัพเดทเองด้วยสคริปต์ · LOCAL-ONLY

*** สำคัญ: กลุ่ม (C) งบการเงิน อยู่ในเครื่องเท่านั้น (financials.db ไม่ขึ้น GitHub
    ตาม .gitignore) — เวอร์ชันเว็บ (GitHub Pages) จะซ่อนเมนูงบ/FCF/Screener+ ***

เวอร์ชันเว็บ (มือถือ/ไอแพด) ตั้งแต่กลาง ก.ค. 2026 เป็นต้นมา ติดตั้งเป็น "แอป"
บนหน้าจอโฮมได้ (PWA) — เปิดซ้ำเร็วขึ้น และยังเห็นข้อมูลรอบล่าสุดแม้ไม่มีเน็ต

################################################################################
 ส่วนที่ 2 — 4 กลไกการอัพเดท
################################################################################

[1] QUICK UPDATE (ปุ่มในแอป — ใช้บ่อยสุด)
    อัพเดท: ราคา/RS/metrics (เร็ว, คงค่า PE/PBV/mktcap เดิม)
            + Insider/ผู้ถือหุ้นใหญ่
            + Indices (เฉพาะช่วงที่ขาด)
            + Short Sales + NVDR
            + Capital Flow
    ไม่ทำ: ดึง fundamentals ใหม่ (PE/PBV/mktcap), งบการเงิน, P/E ตลาด

[2] FULL REFRESH (ปุ่มในแอป — นานๆ ครั้ง)
    อัพเดท: ราคาย้อนหลังเต็ม (10 ปี)
            + ดึง fundamentals ใหม่ (PE/PBV/mktcap/div จาก SET API)
            + Indices (เต็ม)
            + Capital Flow
    ไม่ทำ: Insider, Short, NVDR (ต้องใช้ Quick Update สำหรับพวกนี้!)
           งบการเงิน, P/E ตลาด

    *** ข้อควรระวัง (asymmetry): ***
    - อยากได้ Insider/Short/NVDR ล่าสุด -> ใช้ QUICK UPDATE (Full ไม่ทำ)
    - อยากได้ PE/PBV/mktcap สด        -> ใช้ FULL REFRESH (Quick คงค่าเดิม)

[3] AUTO (GitHub Actions — อัตโนมัติ)
    รัน 3 รอบ/วัน (จันทร์-ศุกร์): 13:10, 18:30 ICT + 06:00 ทุกวัน
    ทำเกือบทุกอย่างของ Quick+Full ให้อัตโนมัติ แล้ว commit ลง repo
    (ราคา, RS, indices, dr, short, nvdr, flow, insider, breadth, valuation-stats)
    ไม่ทำ: งบการเงิน (local-only), P/E ตลาด (ถ้าไม่มีไฟล์ Excel ใหม่ใน repo)
    นี่คือกลไกที่ทำให้เว็บมือถือ/ไอแพดอัพเดทเองได้โดยไม่ต้องมีใครกดอะไร

[4] MANUAL (สั่งเอง — 2 อย่างที่ไม่มีระบบไหนทำให้)
    (ก) P/E & P/BV ตลาด -> วางไฟล์ Excel แล้วกดปุ่ม (ดูส่วนที่ 6.1)
    (ข) งบการเงิน       -> รันสคริปต์ หรือกดปุ่มในแอป (ดูส่วนที่ 5 และ 6.2)
        - หุ้นไทย: ปุ่มเดียว ไม่มีตัวเลือกความถี่
        - หุ้น DR ต่างประเทศ: มี 2 ปุ่มให้เลือก
            "ดึงเฉพาะที่ขาด/เก่า" = เร็ว ข้ามตัวที่เพิ่งดึงไปไม่เกิน 7 วัน (แนะนำ)
            "ดึงทั้งหมด"          = ช้า ดึงใหม่ทุกตัวเสมอไม่ว่าจะเพิ่งดึงไปหรือไม่

################################################################################
 ส่วนที่ 4 — ระบบงบการเงิน 3 แหล่ง (รายละเอียด)
################################################################################

เก็บทั้งหมดใน financials.db (SQLite, LOCAL-ONLY, ~630 MB)

แหล่งที่ 1: YAHOO FINANCE
  - งบรายปี (source 'yahoo')      : ละเอียดสุด ~54 income/76 balance/61 cashflow field
                                     ย้อนหลัง ~5 ปี · มี inventory/ลูกหนี้/PP&E/FCF ครบ
  - งบรายไตรมาส (source 'yahoo_q') : ละเอียด ~6 ไตรมาสล่าสุด (สะสมเพิ่มทุกรอบ sync)
  - ครอบคลุม: หุ้นไทย + DR ทุกตลาด (รวมญี่ปุ่น/ยุโรปที่ Finnomena ไม่มี)

แหล่งที่ 2: SET.OR.TH (source 'set')
  - งบทางการ ~39 field · หุ้นไทยเท่านั้น · มี ratio ทางการ + ธง restatement
  - ใช้เทียบข้าม-check กับ Yahoo (เตือนถ้าต่างกัน >5%)

แหล่งที่ 3: FINNOMENA (source 'finnomena_q')  ★ จุดแข็งหลัก
  - งบรายไตรมาสย้อนยาวสุด ~65 ไตรมาส (16 ปี, ตั้งแต่ 2010)
  - ครอบคลุม 3 ตลาด: ไทย, US, HK เท่านั้น (ไม่มี ญี่ปุ่น/ยุโรป/จีน A-share)
  - เก็บ 27 field/ไตรมาส: income(5) balance(4) cashflow(4+D&A)
                          ratios(7: GPM/NPM/ROA/ROE/DE/SGA%/CashCycle)
                          valuation(7: Close/MktCap/PE/PBV/EV-EBITDA/DivYield/BVPS)
  - เก็บ 2 ที่:
      (ก) FINN:{ตลาด}:{ชื่อ}  = mirror ทั้งตลาด (US ~24k มีงบ, HK ~3k มีงบ)
      (ข) key รายตัว          = หุ้นในพอร์ต (sync ผ่าน update_financials.py)
  - "bridge" อ่านตัวรายตัวก่อน ถ้าไม่มีค่อยตกไป mirror

  - งบรายปี Finnomena (finnomena_y): รวมจากไตรมาสให้อัตโนมัติ ย้อนได้ ~16 ปี
    ใช้ได้กับทุกหุ้นแล้ว (เดิมหุ้นปีบัญชีไม่ตรงปฏิทิน เช่น NVDA/MSFT จะกดดูไม่ได้
    เลย — ตอนนี้ดูได้หมด แต่จะมีป้ายเตือนบอกว่าตัวเลขเทียบกับปีบัญชีจริงของ
    บริษัทได้แม่นแค่ไหน อ่านป้ายสีก่อนใช้: เขียว=ตรง, เหลือง=ใกล้เคียง,
    แดง=ต่างมาก ใช้ดูแนวโน้มได้แต่อย่าเทียบตัวเลขตรงๆ ข้ามแหล่ง)

หมายเหตุความลึกงบตามตลาด:
  - หุ้นไทย + DR-US + DR-HK  = Finnomena 16 ปี + Yahoo ละเอียด  (เต็ม)
  - DR ญี่ปุ่น/ยุโรป/จีน A-share = Yahoo อย่างเดียว ~5 ปี (Finnomena ไม่ครอบคลุม)
  - หุ้นเอกชนไม่จดทะเบียน (เช่น SpaceX) / ETF = ไม่มีงบเลย

หมายเหตุคุณภาพข้อมูล:
  - Cash Cycle ของ Finnomena เพี้ยน -> ระบบคำนวณเองจาก Yahoo (DIO+DSO-DPO)
  - ratio ที่เพี้ยนผิดปกติ (เช่น net margin >200%) ถูกกรองออกจาก Screener+ แล้ว
    (winsorize อัตโนมัติ — ไม่โผล่มาดันอันดับให้เพี้ยน)
  - P/S ของหุ้นฮ่องกงที่รายงานผลครึ่งปี (ไม่ใช่รายไตรมาส) คำนวณถูกต้องแล้ว
    (เดิมเคยต่ำกว่าจริง ~2 เท่าเพราะเข้าใจผิดว่าเป็นรายไตรมาส — แก้แล้ว)
  - PE/เงินปันผลของหุ้นที่เลิกซื้อขาย/ข้อมูลเก่าค้าง จะไม่โผล่เป็นตัวเลขหลอกๆ
    อีกต่อไป (ระบบเช็คความสดของข้อมูลก่อนแสดงแล้ว)
  - หุ้น US mirror ที่เป็น OTC/foreign (ticker ลงท้าย F/Y) หรือเลิกซื้อขายไปแล้ว
    ถูกกรองออกจาก Screener+ แล้ว

  4. เปิดแอป -> เมนู Valuation -> กดปุ่ม "⟳ อัพเดทข้อมูล P/E & P/BV"

--- 6.2  งบการเงิน (เมนู งบการเงิน / FCF Yield / Screener+) ------------------
  ทำผ่านสคริปต์ (ดูส่วนที่ 5) หรือปุ่มในแอป:
  - หน้า "งบการเงิน" ปุ่ม "🔄 อัพเดทงบการเงินทั้งหมด" = หุ้นไทย (Yahoo+SET+Finn-Q)
    ดึงใหม่ทุกตัวเสมอ ไม่มีโหมดเลือกความถี่
  - หน้า "DR/DRx" มี 2 ปุ่ม:

      "📥 ดึงทั้งหมด (local)" = ดึงใหม่ทุกตัวไม่ว่าจะเก่าหรือใหม่ — ใช้เฉพาะตอน

  *** แนะนำใช้ python update_financials.py แทนกดปุ่มทีละหน้า — ทำครบทุกขั้น

--- Screener+ (Fundamental Screener) ---------------------------------------
  - กรองหุ้นด้วยงบ 3 แหล่งรวมกัน · เลือก preset แล้วปรับตัวเลขเองได้
  - Universe: ไทย / DR ในพอร์ต / US ทั้งหมด (~4k) / HK ทั้งหมด (~1.2k)
    (US/HK กรองฝั่ง server ส่งกลับ ≤500 อันดับแรก)
  - Preset: CANSLIM (พื้นฐาน + ครบสูตรรวมราคา), Quality Compounder,
            คุณภาพกำไร, Value ในอดีตตัวเอง, Net Cash, Turnaround,
            Dividend Safety, Dividend Growth, GARP (PEG≤1), เข้าไฮซีซั่น,
            🌊 วอลุ่มจุดชนวน, 💥 Breakout มีของจริง,
            🇺🇸 US หุ้นดีราคาถูก, 🇭🇰 HK หุ้นดีราคาถูก (สลับ universe ให้อัตโนมัติ)
  - Filter เด่น: กำไรเร่งตัว, ROE/ROA (รวม ROE≥15% ต่อเนื่องกี่ไตรมาส), OCF/NI
    (จับหุ้นแต่งบัญชี), PE/PBV/PS percentile (ถูกกว่าอดีตตัวเอง), เทียบกับ
    ค่าเฉลี่ยกลุ่มอุตสาหกรรมเดียวกัน (หุ้นไทย), cash cycle, net cash, ฤดูกาล,
    RS/ระยะห่างจาก high 52 สัปดาห์ (เทคนิคผสมพื้นฐาน) ฯลฯ
  - ตารางผลลัพธ์: มีสีบอกความหมาย (เขียว=ดี, แดง=เสี่ยง/แพง), โชว์ชื่อบริษัท
    ใต้ ticker, กดชื่อหุ้นเปิดหน้างบการเงินของตัวนั้นได้ทันที
  - หมายเหตุ: หุ้น US/HK นอกพอร์ตใช้งบ Finnomena ล้วน -> filter ที่ต้องใช้ Yahoo
    (net cash/cash cycle/goodwill/buyback/FCF/CAGR/interest coverage) จะใช้ไม่ได้
    (ช่องพวกนี้จะจางลงอัตโนมัติเมื่อเลือก universe US/HK)

--- ผลวิจัย backtest (กดดูได้ในหน้า Screener และ Screener+) -----------------
  ปุ่ม "📊 ผลวิจัย backtest ทั้งสองแบบ" สรุปว่า preset ไหน "ทำเงินจริง" จาก
  การทดสอบย้อนหลังหุ้นไทย 2012-2026 (44,673 ตัวอย่าง):
  - 💥 Breakout มีของจริง และ 🏆 CANSLIM ให้ผลตอบแทนเหนือตลาดสม่ำเสมอที่สุด
  - 🌊 วอลุ่มจุดชนวน ผลตอบแทนเฉลี่ยดีแต่ "ชนะไม่บ่อย" (สไตล์ high risk)
  - มีตารางสรุประยะเวลาที่หุ้นมักวิ่งก่อนหมดรอบด้วย (ประมาณ 3-4 เดือน)
  รันเพิ่มเองได้ด้วย python backtest_screener.py TH (ดูส่วนที่ 5)

--- Stock Screener (เมนู "Screener" ตัวเดิม — เน้นราคา/เทคนิค) --------------
  - Preset สำเร็จรูป: ต้นรอบ, Strong Momentum, Breakout, 💥 Breakout มีของจริง,
    Near ATH, High Yield, Value Turnaround, CANSLIM, โต+คนในซื้อ, 🌊 วอลุ่มจุดชนวน
  - ช่อง RVOL (ปริมาณซื้อขายเทียบเฉลี่ย) หน่วยเป็น "เท่า" แล้ว (เช่น 1.5 = สูง
    กว่าเฉลี่ย 1.5 เท่า) — ตรงกับหน่วยของ Screener+ ใส่เลขเดียวกันได้ผลตรงกัน
  - มีสัญญาณเทคนิค "🔁 เหนือ/เพิ่งตัดขึ้น EMA200" เพิ่มเข้ามา (จับหุ้นที่เพิ่ง
    กลับตัวเป็นขาขึ้น ไม่ใช่แค่หุ้นที่เป็นขาขึ้นมานานแล้ว)
  - PEG ใช้สูตรเดียวกับ Screener+ แล้ว (P/E หารด้วยอัตราการเติบโตของกำไร)

  - โหมด "งบรายปี Finnomena" (finnomena_y) ใช้ได้กับหุ้นต่างประเทศทุกตัวแล้ว
    รวมหุ้นปีบัญชีไม่ตรงปฏิทิน (NVDA/MSFT ฯลฯ) — จะมีป้ายสีบอกว่าตัวเลขปีนั้น
    เทียบกับปีบัญชีจริงของบริษัทได้แม่นแค่ไหน (เขียว/เหลือง/แดง) อ่านป้ายก่อนใช้
  - ปุ่ม TradingView บนหัวหน้างบการเงิน (เฉพาะแท็บ DR — US/HK) เปิดกราฟหุ้นตัวนั้น

    (ทดสอบแล้วว่า resolve ticker ได้ครบ US 3,930 + HK 1,178 ตัว)
  - ตาราง "อัตราส่วนการเงิน (Ratios)" และ "มูลค่า / Valuation" (โหมด Finnomena)
    มีไอคอน ℹ ให้กดดูคำอธิบายแต่ละรายการแล้ว เหมือนตารางงบ 3 อย่างหลัก

  *** เปิดจากเครื่อง (local) = อัตโนมัติ *** — พอหุ้น DR ตัวใหม่ถูกเพิ่มเข้า

  *** เปิดจากเว็บมือถือ/ไอแพด = "ไม่" อัตโนมัติ *** — เว็บมือถือไม่มี backend
  ให้ดึงสดได้ เห็นได้แค่ข้อมูลที่ bake ไว้ล่วงหน้าในไฟล์ data/dr_descriptions.json
  เท่านั้น ถ้าหุ้นใหม่ยังไม่เคยถูกดึงในเครื่องมาก่อน กล่องนี้จะไม่โผล่บนมือถือ
  (ไม่ error แค่ไม่มีข้อมูลให้แสดง) — อยากให้เว็บมือถือเห็นหุ้นตัวใหม่ ต้องทำ:
      1. เปิดดูหุ้นตัวนั้นในเครื่องสักครั้ง (หรือกดปุ่ม "📖 ดึงคำอธิบายบริษัท DR")
      2. รัน run_static_update.py (หรือรอรอบ auto-update ปกติ) เพื่อ bake ใหม่
      3. push ขึ้น GitHub

 ส่วนที่ 9 — เกร็ด/Troubleshooting
################################################################################

- ไม่เห็นข้อมูลใหม่หลังอัพเดท -> Hard refresh browser (Ctrl+Shift+R) กัน cache
- Screener+/งบ ขึ้น "ใช้ได้เฉพาะ local" -> ถูกต้อง เพราะเป็น local-only
- DR ใหม่ไม่มีชื่อ/ดึงงบไม่ได้ -> ถ้า derive ticker ไม่ได้ ต้องเพิ่มใน _DR_STATIC เอง
  (ดูหน้า DR ปุ่ม "🔍 เช็คหุ้นใหม่/ถูกถอด" — ตอนนี้แยกให้แล้วว่าตัวไหน "ต้องเพิ่มจริง"
  กับตัวไหนแค่ SET เปลี่ยนชื่อรหัสภายในแต่ข้อมูลมีอยู่แล้ว ไม่ต้องทำอะไร)
- mirror ดูเหมือนค้าง -> อาจกำลัง "พักเบรกกันแบน" (สุ่ม 3-14 นาที) เช็คด้วย check_mirror
- งบ Finnomena มีงบรายปีด้วย (quarter=9) แต่ระบบเก็บเฉพาะรายไตรมาส แล้วรวมเป็น
  รายปีเอง (โหมด "งบรายปี Finnomena" ในหน้างบการเงิน — ดูส่วนที่ 7)
- ข้อมูล SET P/E ช้า ~1 เดือนเป็นปกติ ไม่ใช่ค้าง (หน้า Valuation บอกเดือนข้อมูล)
- RVOL ในหน้า Screener (ตัวเดิม) เปลี่ยนหน่วยจาก % เป็น "เท่า" แล้ว — ถ้าเคย
  บันทึกค่ากรองไว้เป็น 150/200 (แบบ %) ระบบแปลงให้อัตโนมัติเป็น 1.5/2.0 ตอน
  เปิดแอปครั้งแรกหลังอัพเดท ไม่ต้องแก้เอง
- ไม่เห็นกล่อง "📖 เกี่ยวกับบริษัท" -> ปกติ ถ้ายังไม่เคยเปิดดูหุ้นตัวนั้นในเครื่อง
  มาก่อน (บนเว็บมือถือต้อง sync+bake+push ก่อน ดูส่วนที่ 7) หรือ Yahoo ไม่มี
  business summary ให้หุ้นตัวนั้นจริงๆ (พบได้กับหุ้นเล็ก/เพิ่ง IPO)

รอบการอัพเดทที่แนะนำ:
  ทุกวันทำการ    -> Quick Update (ในแอป) หรือปล่อย GitHub Actions auto
  ทุกเดือน       -> วาง Table_PE/PBV.xls ใหม่ (เตือนวันที่ 10)
  หลังงบไตรมาส   -> python update_financials.py (ก.พ./พ.ค./ส.ค./พ.ย.)
                    หรือกด "🔄 อัพเดทงบการเงินทั้งหมด" + "🔄 ดึงเฉพาะที่ขาด/เก่า"
  ไตรมาสละครั้ง  -> python mirror_finnomena.py force (US/HK ทั้งตลาด, กลางคืน)

 ส่วนที่ 11 — ถ้า Finnomena ตาย/เปลี่ยน API (แผนสำรอง + degrade matrix)
################################################################################

Finnomena เป็นแหล่งเดียวที่ให้งบไตรมาสย้อนยาว 16 ปี (ตั้งแต่ 2010) ของหุ้นไทย+
US+HK ทั้งตลาด แต่ "ไม่มี API ทางการ" (ระบบดึงผ่าน endpoint ภายในของเว็บ) —
เสี่ยงสุดในบรรดาแหล่งข้อมูลทั้งหมดที่ dashboard ใช้ เพราะถ้าปิด/เปลี่ยนรูปแบบ
เมื่อไหร่ ข้อมูล 16 ปีที่ mirror มาแล้วจะ "สร้างใหม่ไม่ได้อีกเลย" (ต่างจากราคา
หุ้นที่ Yahoo/SET ดึงย้อนหลังใหม่ได้เสมอ)

--- หลักคิด ---
ข้อมูลที่ mirror มาแล้วอยู่ใน financials.db "เป็นของเราแล้ว" ถาวร ต่อให้ Finnomena
ปิด API พรุ่งนี้ ประวัติเดิมไม่หาย แค่ไม่มีงวดใหม่เติมเข้ามาเท่านั้น ความเสี่ยงจริง
คือ "เครื่อง/ฮาร์ดดิสก์พัง" หรือ "ไฟล์เสีย" มากกว่า Finnomena ปิดตัว

--- 11.1 สำรองนอกเครื่อง (ป้องกันความเสี่ยงใหญ่สุด) ---
financials_backups/ ในเครื่อง (เก็บอัตโนมัติ 3 ชุดล่าสุด) กันไฟล์เสีย/เขียนพลาด
ได้ แต่ไม่ช่วยถ้าโน้ตบุ๊คหาย/ฮาร์ดดิสก์พังทั้งลูก — ต้องมีสำเนานอกเครื่องด้วย:

    python backup_financials_offsite.py D:\Backups\SET_Dashboard
    (หรือดับเบิลคลิก backup_financials_offsite.bat แล้วพิมพ์ path เมื่อถาม)

  ทำอะไร: คัดลอก financials.db (~630MB) ไปปลายทางที่ระบุ (external drive /
  โฟลเดอร์ cloud sync เช่น Google Drive/OneDrive) เก็บ 3 ชุดล่าสุด ชุดเก่ากว่า
  ลบทิ้งอัตโนมัติ + บันทึกเวลาไว้ให้หน้า "🩺 Data Health" ในแอปเห็น
  ความถี่: เดือนละครั้งพอ — หน้า Data Health จะขึ้นแดงเตือนเองถ้าเกิน 35 วัน
