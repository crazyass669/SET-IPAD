 4. โครงสร้างนำทาง (ตัดสินใน session — นี่คือข้อเสนอ)
--------------------------------------------------------------------------------

ตอนนี้ 5 ปุ่มล่าง: ตลาด / หุ้น / วอทช์ลิสต์ / หมุนเวียน / เพิ่มเติม
มี ~12 หน้าหลังพอร์ต -> "เพิ่มเติม" ต้องเป็นเมนูจริง (ไม่ใช่ข้อความ)

ข้อเสนอ:
  ปุ่มล่าง 5: [ตลาด] [หุ้น] [วอทช์ลิสต์] [เงินทุน] [เพิ่มเติม]
    - เงินทุน = แท็บย่อยในหน้าเดียว: Capital Flow / Short / Insider / สัญญาณรวม
    - เพิ่มเติม = เมนูจริง -> หมุนเวียนกลุ่ม · ดัชนีกลุ่ม · Heatmap · Valuation ·
                  Screener · Screener+
  หรือคงหมุนเวียนไว้ที่ปุ่มล่าง แล้วยุบวอทช์ลิสต์เข้าเพิ่มเติม — ให้ผู้ใช้เลือก

pattern nav: `go(scr)` + `#s-<scr>` screen div + `renderXxx()` มีอยู่แล้วใน app.js
เมนู "เพิ่มเติม" ที่เป็น navigation จริง: ทำ mitem ให้ addEventListener -> go()
