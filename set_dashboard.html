FCF Yield & Dividend Coverage
Free Cash Flow ÷ Market Cap และเช็คว่าปันผลจ่ายจาก FCF จริงหรือไม่ — คำนวณจากงบการเงินที่ดึงเก็บไว้ในเครื่อง (local-only)
📘 อธิบายค่าที่เห็นในตารางนี้ (สำหรับคนที่ยังไม่คุ้น)
Free Cash Flow (FCF) คืออะไร?
เงินสดที่บริษัทเหลือจริงๆ หลังจากหักค่าใช้จ่ายในการดำเนินธุรกิจและลงทุนในสินทรัพย์ (เช่น เครื่องจักร โรงงาน) ไปแล้ว เป็นเงินที่บริษัท "เอาไปทำอะไรก็ได้" — จ่ายปันผล ซื้อหุ้นคืน ใช้หนี้ หรือเก็บสำรองไว้ — ต่างจาก "กำไรสุทธิ" ที่เป็นตัวเลขทางบัญชี อาจไม่ใช่เงินสดจริงในมือ
FCF Yield = FCF ÷ Market Cap × 100
เทียบเงินสดที่บริษัทหาได้ต่อปี กับราคาที่ตลาดตีมูลค่าบริษัทไว้ทั้งหมด — คล้ายอัตราดอกเบี้ยที่จะได้ถ้า "ซื้อบริษัททั้งบริษัท" ยิ่งสูงยิ่งดี (จ่ายราคาถูกเทียบกับเงินสดที่ได้)
ตัวอย่าง: บริษัท A มูลค่าตลาด (Market Cap) 10,000 ล้านบาท ปีที่แล้วสร้าง FCF ได้ 500 ล้านบาท
FCF Yield = 500 ÷ 10,000 × 100 = 5%
แปลว่า ถ้าซื้อบริษัท A ทั้งบริษัทด้วยเงิน 10,000 ล้าน จะได้เงินสดกลับมาปีละ 5% ของเงินที่จ่ายไป — เทียบกับดอกเบี้ยเงินฝาก/พันธบัตรที่ต่ำกว่านี้มาก ถือว่าน่าสนใจ ถ้าธุรกิจยังโตต่อได้
ต่ำกว่า 2%ต่ำ — แพงเทียบกับเงินสดที่หาได้ หรือกำลังลงทุนหนักช่วงนี้
2 – 5%ปานกลาง — ใกล้เคียงค่าเฉลี่ยตลาด
5 – 10%ดี — เงินสดคุ้มค่าเมื่อเทียบกับราคา
สูงกว่า 10%สูงผิดปกติ — ควรเช็คว่าเป็น FCF จริงจากธุรกิจ หรือเป็นรายการพิเศษ (เช่น ขายสินทรัพย์) ที่ปีหน้าอาจไม่มีซ้ำ
Dividend Coverage = FCF ÷ เงินปันผลที่จ่ายทั้งปี
เช็คว่าเงินที่เอาไปจ่ายปันผล "มาจากเงินสดที่หาได้จริง" หรือ "จ่ายเกินตัว" ต้องไปกู้/ถอนเงินสำรองมาจ่ายแทน
ตัวอย่างที่ 1 (ปลอดภัย): บริษัท B สร้าง FCF ได้ 500 ล้านบาท จ่ายปันผลทั้งปี 300 ล้านบาท
Coverage = 500 ÷ 300 = 1.67x
ทุกๆ 1 บาทที่จ่ายปันผล บริษัทหาเงินสดมาได้ 1.67 บาท — จ่ายแล้วยังเหลือเงินสดเก็บไว้ในบริษัทอีก 200 ล้าน ถือว่าปันผลมั่นคง

ตัวอย่างที่ 2 (ต้องระวัง): บริษัท C สร้าง FCF ได้แค่ 200 ล้านบาท แต่จ่ายปันผลทั้งปี 300 ล้านบาท
Coverage = 200 ÷ 300 = 0.67x
จ่ายปันผลมากกว่าเงินสดที่หาได้ 100 ล้านบาท — ส่วนต่างนี้ต้องมาจากการกู้เงิน ถอนเงินสำรองเก่า หรือขายสินทรัพย์ ถ้าเกิดขึ้นต่อเนื่องหลายปี อาจต้องลดปันผลในอนาคต
มากกว่า 1.5xปลอดภัย — เงินสดเหลือเฟือ ปันผลมั่นคง
1.0 – 1.5xพอไหว — จ่ายได้แต่ไม่มีกันชนมาก
ต่ำกว่า 1.0xควรระวัง — จ่ายปันผลเกินเงินสดที่หาได้จริง
— (ไม่มีค่า)บริษัทไม่ได้จ่ายปันผลปีล่าสุด — ไม่มีอะไรให้เทียบ

ℹ
แสดง net buy/sell (ซื้อ-ขายสุทธิ) ของนักลงทุนแต่ละกลุ่มใน 3 ตลาด: SET / S50 Futures / Thai Bond

ตัวเลข เขียว (+) = ซื้อสุทธิ (เงินไหลเข้า), แดง (−) = ขายสุทธิ (เงินไหลออก)

การ์ดด้านบน = สะสม 20 วันล่าสุดของแต่ละตลาด (ดูรายละเอียดแต่ละการ์ดได้ที่ไอคอน ℹ) ส่วนกราฟ/ตารางด้านล่างสลับตลาด+ช่วงเวลาได้เอง
💡 ความสัมพันธ์ SET / S50 Futures / Thai Bond
🔗 ความสัมพันธ์ของ 3 ตลาดนี้กับ SET
1) ธรรมชาติของแต่ละตลาดต่างกัน
ตลาดคืออะไรหน่วยความหมาย
SET (cash)ซื้อขายหุ้นจริงล้านบาทเงินจริงไหลเข้า/ออกตลาดหุ้น — ผลต่อราคาโดยตรง
S50 Futuresอนุพันธ์อ้างอิงดัชนี SET50 (หุ้นใหญ่ 50 ตัว ~80% ของ market cap)สัญญา (ไม่ใช่บาท)โพซิชั่น/มุมมองทิศทาง — ไม่ใช่เงินไหลเข้าจริงเสมอไป
Thai Bondตราสารหนี้รัฐบาล/เอกชนล้านบาทเงินจริงไหลเข้า/ออกตลาดตราสารหนี้ — สะท้อนมุมมองดอกเบี้ย/ค่าเงินบาทมากกว่าหุ้น
จุดสำคัญ: S50 Futures ไม่ใช่เงินไหลเข้าจริงแบบ SET/Bond — เป็นสัญญาที่ใช้ได้ทั้ง (ก) เก็งกำไรทิศทาง (ข) hedge พอร์ตหุ้นที่ถืออยู่ (ขาย futures ป้องกันขาลง โดยไม่ต้องขายหุ้นจริง) (ค) arbitrage ระหว่างราคา cash SET50 กับราคา futures ดังนั้นต่างชาติ net long S50 เพิ่ม ไม่ได้แปลว่ามีเงินไหลเข้าตลาดหุ้นเพิ่มเสมอไป
2) พฤติกรรม 3 กลุ่มนักลงทุน — ต่างชาติ / สถาบัน / รายย่อย
คอลัมน์ "ต่างชาติ/กองทุน+โบรก(สถาบัน)/รายย่อย" ในการ์ด SET กับ S50 ด้านบน แต่ละกลุ่มมีบทบาทต่างกัน:
ต่างชาติ (Foreign) — มีอิทธิพลต่อทิศทาง SET มากที่สุด มักเป็น "ตัวชี้วัดหลัก" ของ fund flow ถ้าซื้อสุทธิในหุ้น SET พร้อมเปิด net long ใน S50 Futures ควบคู่กัน มักเป็นสัญญาณบวกที่แข็งแกร่งที่สุด และมักสัมพันธ์กับ flow ที่เข้า/ออก Thai Bond ด้วยเช่นกัน (เงินก้อนเดียวกันเคลื่อนข้ามสินทรัพย์)
สถาบัน/กองทุน (Institutions) — มักใช้ S50 Futures เพื่อ hedge พอร์ตหุ้นระยะยาวที่ถืออยู่ (ไม่ใช่เก็งกำไรทิศทางตรงๆ) ถ้าถือหุ้นไทยสัดส่วนสูงอยู่แล้ว มักเปิด net short ใน S50 สวนไว้เพื่อลดความผันผวน — เห็น net short เพิ่มจึงไม่ใช่มุมมองลบเสมอไป และมักเป็นกลุ่มที่ปรับสัดส่วน (asset allocation) ระหว่างหุ้นกับ Thai Bond เอง
รายย่อย (Retail) — มักมีพฤติกรรมสวนแนวโน้ม/ตามรอบระยะสั้น (counter-cyclical) เมื่อตลาดขึ้นแรงและต่างชาติเทขาย รายย่อยมักเข้าเป็นฝั่งรับซื้อสวนทาง — ใช้เป็นสัญญาณ contrarian ได้บ้าง แต่ไม่ควรใช้เดี่ยวๆ
3) กลไกที่เชื่อมโยงกัน
S50 Futures ↔ SET cash: ต่างชาติมักเทรด futures ก่อน cash เพราะเร็วกว่า/ต้นทุนต่ำกว่า (ไม่ต้องโอนเงินข้ามประเทศทันที) ดังนั้น net position ของ S50 บ่อยครั้ง "นำ" ทิศทางของ flow ใน cash SET ไป 1-2 วัน หรือเกิดพร้อมกัน (มีบทบาท price discovery ระยะสั้น)

Thai Bond ↔ ค่าเงินบาท ↔ SET: ต่างชาติซื้อพันธบัตรไทย ต้องแลกดอลลาร์เป็นบาท → บาทแข็งขึ้น ซึ่งกระทบหุ้นกลุ่มส่งออก/นำเข้าทางอ้อม และมักเป็นสัญญาณ risk-on ต่อประเทศไทยโดยรวม — เป็นคนละ driver จากหุ้น (ที่ขึ้นกับ earnings/valuation รายตัว) แต่บ่อยครั้งเคลื่อนไหวสอดคล้องกันเพราะกองทุนเดียวกันจัดพอร์ต multi-asset ในไทยพร้อมกัน
ลำดับ fund flow แบบทั่วไป (waterfall): FX → Thai Bond → หุ้นใหญ่ (SET50) → SET Index → หุ้นกลาง/เล็ก
เงินต่างชาติมักเข้าตลาดบอนด์/ค่าเงินก่อน ตามด้วยหุ้นใหญ่ผ่าน S50 Futures/SET50 แล้วค่อยไหลลงมาสู่หุ้นกลาง-เล็กทีหลังสุด — ถ้าเห็นบอนด์+S50 ขยับก่อน มักเป็นสัญญาณเตือนล่วงหน้าว่า SET Index กำลังจะตาม
4) เสริม: อ่านสถานะคงค้าง (Open Interest) ของ S50 Futures
Open Interest (OI) = จำนวนสัญญาที่ยังเปิดค้างอยู่ (ไม่รวมที่ปิดสถานะแล้ว) ใช้ดูคู่กับราคา futures เพื่อเช็คว่า "แรงจริง" หรือแค่ปิดสถานะเดิม — หมายเหตุ: dashboard นี้ยังไม่ได้ดึงข้อมูล OI มาแสดง เป็นแนวคิดเสริมสำหรับดูจากแหล่งอื่นประกอบ
ราคาขึ้น + OI เพิ่มแนวโน้มแข็งแรง (มีเงินใหม่เข้ามา long จริง)
ราคาขึ้น + OI ลดShort Covering (แค่ปิดสถานะช็อตเดิม ไม่ใช่แรงซื้อใหม่)
ราคาลง + OI เพิ่มเปิด Short ใหม่ (แรงขายจริง)
ราคาลง + OI ลดLong Liquidation (แค่ปิดสถานะซื้อเดิม ไม่ใช่แรงขายใหม่)
5) กรอบการอ่านสัญญาณ (confluence vs divergence)
สอดคล้องกันทั้ง 3 ตลาด = สัญญาณแรงสุด
• ซื้อ SET (+) + long S50 (+) + ซื้อพันธบัตร (+) → risk-on ไทยเต็มรูปแบบ เงินไหลเข้าจริงทุกสินทรัพย์
• ขาย SET (−) + short S50 (−) + ขายพันธบัตร (−) → risk-off ไทย เงินไหลออกทุกสินทรัพย์ (มักมาพร้อมบาทอ่อน)
ไม่สอดคล้องกัน = ต้องตีความเพิ่ม ไม่ใช่แปลตรงตัว
• ขาย SET cash แต่ long S50 เพิ่ม → อาจเป็นการ cover/ลด hedge (เคยชอร์ต futures ป้องกันขาลง ตอนนี้เริ่มคลายความกังวล) ไม่ใช่ว่าซื้อหุ้นเพิ่มจริง
• ซื้อ SET แต่ short S50 เพิ่ม → อาจเป็นการ เปิด hedge ป้องกันกำไรที่มีอยู่ ไม่ใช่สัญญาณลบต่อตลาด
• ขายพันธบัตรแต่ซื้อหุ้น → มุมมองดอกเบี้ยขาขึ้น (บอนด์ราคาตก) แต่ยังเชื่อมั่นหุ้น/earnings — เป็น rotation ระหว่างสินทรัพย์ ไม่ใช่เงินไหลออกประเทศ
6) ตัวอย่างจริง (20 วันสะสม)
• SET: ต่างชาติ +36,366 ล้านบาท (ซื้อสุทธิแรง)
• S50 Futures: ต่างชาติ +24,582 สัญญา (long เพิ่ม — สอดคล้องทิศทางเดียวกับ SET)

ครึ่งหนึ่งของสัญญาณจบใน ~2 สัปดาห์ แต่ตัวที่จับเทรนด์ใหญ่ได้ลากยาวเป็นปี — การกระจายเบ้ขวามาก ตอบเป็นตัวเลขเดียวไม่ได้
"วันที่เส้นตัดกัน" ใช้ไม่ได้ — "ระดับความแรง" ใช้ได้
  • Crossover เฉยๆ แทบไม่มี edge: หลังวัน NH แซง NL — median ที่ SET อยู่เหนือราคาวันสัญญาณ = 0 วัน (ครึ่งหนึ่งหลุดวันถัดไป)
  • ฝั่ง bearish crossover กลับให้ผล 5 วันถัดไปเป็นบวก (+0.43%, win 65%) เพราะกว่า NL จะแซง NH ตลาดมักลงลึกแล้ว เกิด rebound สวน
ผลตอบแทน SET ต่อปี แยกตามสภาวะ breadth (ค่าเฉลี่ยรวมทุกวัน = +5.8%)
สภาวะ NH−NL (net)ผลตอบแทน SET ต่อปี
net > +20 (broad strength)+19.1%
net > 0 (NH>NL เฉยๆ)+12.0%
net < 0 (NL>NH เฉยๆ)+1.2% (ทรงตัว ไม่ได้ลงแรง)

net < −50 (panic breadth)−16.2%
Breadth thrust แรงๆ พยากรณ์ได้ไกล
  • วันแรกที่ net ทะลุ +20: SET บวกต่อเนื่องทุก horizon ถึง 120 วัน (win rate 58→70%)
  • วันแรกที่ net หลุด −50: SET ยังลบต่ออีก 1–6 เดือน (win แค่ 40–50%) — ฝั่งลบไม่เกิด rebound แบบ crossover ธรรมดา
สรุปใช้งานจริง
  • อย่าเทรดจากวันที่เส้นตัดกัน — ใช้ระดับแทน: net > +20 = สภาพแวดล้อมขาขึ้นของจริง (ถือได้เป็นเดือน), net < −50 = อย่าเพิ่งรีบช้อน แนวโน้มลงยังไม่จบ
  • ช่วง NL > NH แบบตื้นๆ ไม่ใช่สัญญาณขาย — ตลาดแค่ทรงตัว (+1.2%/ปี ไม่ใช่ติดลบ)
